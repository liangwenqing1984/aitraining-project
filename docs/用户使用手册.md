# 用户使用手册

## 一、登录系统

系统支持两种登录方式：

### 本地账号登录
输入用户名和密码，勾选"记住我"可保存登录状态。

**默认账号**：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| `admin` | `Admin@admin123` | 管理员 |
| `user` | `User@123456` | 普通用户 |
| `test` | `Test@123456` | 测试用户 |

### OAuth2 统一认证
点击"统一认证"标签，跳转到企业认证中心完成登录。

## 二、数据采集

### 2.1 创建采集任务

1. 进入"数据采集"页面
2. 点击"新增任务"
3. 填写配置：
   - **任务名称**：自定义名称
   - **数据源**：智联招聘 / 前程无忧(51job)
   - **搜索关键词**：如 Java、Python、前端
   - **工作城市**：选择目标城市
   - **采集页数**：1–50 页（每页约 20–60 条）
   - **并发数**：1–3（建议 2）
4. 点击"创建并启动"

### 2.2 批量创建任务

点击"批量创建"可一次创建多个任务组合（多关键词 × 多城市）。

### 2.3 监控任务进度

点击任务行的"监控"按钮进入实时监控页面，可看到：
- 进度百分比和已抓取/总数
- 实时日志流
- 当前状态（运行中/暂停/完成/失败）

### 2.4 控制任务

| 操作 | 说明 |
|------|------|
| 启动 | 开始或恢复抓取 |
| 暂停 | 暂停当前抓取（可恢复） |
| 停止 | 终止任务（不可恢复） |
| 编辑配置 | 修改任务参数（需先停止） |

## 三、数据管理

进入"数据管理"页面查看所有已完成的采集文件。

### 操作列表

| 操作 | 说明 |
|------|------|
| 预览 | 查看前 20 行数据 |
| 下载 | 下载完整 CSV 文件 |
| 分析 | 跳转到智能分析页面 |
| 删除 | 删除文件及关联数据 |

## 四、智能分析

选择 CSV 文件后可查看多维度统计图表：

| 维度 | 图表类型 | 说明 |
|------|---------|------|
| 薪资分布 | 柱状图/箱线图 | 各薪资区间岗位数 |
| 城市分布 | 饼图/地图 | 城市岗位数量占比 |
| 学历要求 | 柱状图 | 不同学历层次需求 |
| 经验要求 | 柱状图 | 不同经验年限需求 |

### 生成 AI 洞察报告

点击"生成洞察报告"，AI 会自动分析数据并生成 Markdown 格式的专业报告，包含：
- 关键发现和趋势总结
- 数据解读和商业建议
- 配套 ECharts 图表

## 五、数据看板

进入"数据看板"页面，直观查看系统核心指标：
- 任务总数、职位数、城市覆盖数
- 数据采集趋势图
- AI 增强覆盖率
- 可生成 AI 全量洞察综合报告

### 数据大屏

进入"数据大屏"页面，全屏展示科技蓝风格的数据可视化大屏，适合投屏展示。

## 六、智能查询

用自然语言提问，AI 自动转换为 SQL 查询。

**示例问题**：

- "北京 Java 岗位薪资 20K 以上的有哪些"
- "哈尔滨和沈阳的前端岗位数量和薪资对比"
- "要求本科学历的 Python 岗位占比多少"
- "哪些公司提供的福利包含年终奖"

**操作**：
1. 输入问题
2. 可选：限定查询范围（选择任务）
3. 点击"查询"
4. 查看结果表格 + AI 摘要

查询历史会保存，可随时查看和删除。

## 七、语义搜索

基于向量相似度的智能职位搜索，支持模糊语义匹配。

**使用方法**：
1. 进入"语义搜索"页面
2. 输入搜索描述（如"Python 后端开发，使用 Django 框架"）
3. 设置相似度阈值（0.5–0.95，建议 0.7）
4. 可选：限定任务范围
5. 点击"搜索"

**结果排序**：按相似度从高到低排列。

### 数据索引

首次使用需先对数据进行向量化索引：
1. 点击"索引管理"
2. 选择已完成的任务
3. 点击"开始索引"
4. 等待完成（约 1–5 分钟/千条）

## 八、简历筛选

上传简历文件（PDF/DOCX/TXT），系统自动解析文本并向量匹配相似职位。

**使用方法**：
1. 进入"语义搜索 → 简历筛选"
2. 上传简历文件或粘贴简历文本
3. 设置匹配数量和相似度阈值
4. 点击"开始匹配"
5. 查看按相似度排列的匹配职位列表

## 九、AI 问答机器人

进入"系统帮助 → 问答机器人"，可向 AI 提问技术问题。

**能力**：
- 基于 RAG 检索项目文档和源代码
- 支持自然语言技术问答
- 引用来源章节/文件路径

## 十、文档向量管理

进入"系统管理 → 文本向量管理 → 文档向量索引"。

**功能**：
- 按来源类型和关键字搜索文档向量
- 上传文件：支持拖拽或点击上传 .txt/.md/.pdf/.docx，自动解析+向量化，可同时选择多个文件
- 按类型或单条删除向量记录

## 十一、增强数据管理

进入"系统管理 → 增强数据管理"，查看和筛选 AI 增强后的职位数据（标准化薪资、技能、行业分类等）。

## 十二、模型训练

进入"系统管理 → 模型训练"，微调岗位领域专用 Embedding 模型。

**三个 Tab**：
- **训练数据**：选择任务构建对比学习训练数据集
- **训练任务**：配置基座模型和超参数，启动 Python 微调训练
- **模型管理**：查看已训练模型，部署到 Ollama

## 十三、模型配置

进入"系统管理 → 模型配置"，管理系统使用的 AI 模型。

### 添加模型

1. 点击"添加模型"
2. 选择提供商（OpenAI / DeepSeek / Ollama 等）
3. 选择或输入模型名称
   - Ollama：自动从本地获取部署的模型列表
   - 云端：可从预设选择或手动输入
4. 填写 API Key（Ollama 无需填写）
5. 勾选任务分配：
   - **数据增强**：标准化职位数据
   - **智能洞察**：生成分析报告
   - **NL 查询**：自然语言转 SQL
   - **反爬检测**：AI 辅助反爬

### 推荐配置

| 任务 | 推荐模型 | 原因 |
|------|---------|------|
| 数据增强 | Ollama qwen3:14b / DeepSeek | 批量处理，成本低 |
| 智能洞察 | DeepSeek / GPT-4o | 强推理，长文生成 |
| NL 查询 | DeepSeek / 智谱 GLM | 中文 NLU 强 |
| 反爬检测 | Ollama qwen3:4b | 低延迟（<1s） |

## 十四、系统管理（管理员）

### 用户管理

- **新增用户**：填写用户名、密码、真实姓名、邮箱等
- **编辑用户**：修改信息和角色分配
- **删除用户**：不可恢复
- **状态开关**：快速启用/禁用用户
- **角色分配**：多角色选择

### 角色管理

- **基本信息**：角色名称、唯一编码（如 `admin`）、描述
- **菜单分配**：勾选角色可访问的菜单项
- **权限分配**：每个菜单下显示对应的操作权限（创建/编辑/删除/查看）

### 权限管理

权限格式为 `resource:action`（如 `user:create`），按资源（resource）分组管理。

### 菜单管理

树形结构管理前端侧边栏菜单，支持：
- 父子菜单层级
- 路径、图标、排序
- 可见/隐藏控制
- 有子菜单时禁止删除父菜单

### 增强数据管理

查看 AI 增强后的职位标准化数据（薪资、技能、行业分类等），支持按任务筛选。

### 文本向量管理

管理职位向量索引和文档向量索引，支持搜索、删除、文件上传。

### 模型训练

管理 Embedding 模型微调训练：构建数据集 → 启动训练 → 部署模型。

### 模型配置

管理 LLM 提供商和模型，位于"系统管理 → 模型配置"。
