# 系统架构概述

> 日期：2026-05-08

## 一、系统简介

高质量人才数据集平台是一站式招聘数据采集、增强、分析与智能检索系统。支持前程无忧（51job）和智联招聘双源数据自动采集，集成 AI 大模型进行数据增强、市场洞察、自然语言查询和反爬对抗，并提供 RAG 语义搜索能力。

## 二、技术栈

| 层级 | 技术 | 版本/说明 |
|------|------|----------|
| **前端框架** | Vue 3 + TypeScript | Composition API (`<script setup>`) |
| **UI 组件库** | Element Plus | 统一设计系统 |
| **构建工具** | Vite | 开发服务器 + 生产构建 |
| **路由** | Vue Router 4 | Hash/History 模式 |
| **后端框架** | Express (Node.js) | TypeScript |
| **数据库** | PostgreSQL (SeaboxSQL) | 10.1.1.113:7300 |
| **向量扩展** | pgvector | 768 维向量，支持 RAG |
| **实时通信** | Socket.IO | WebSocket 双向推送 |
| **浏览器自动化** | Playwright | 爬虫渲染与数据提取 |
| **LLM 提供商** | OpenAI / Anthropic / DeepSeek / 智谱 / Ollama | 多模型可切换 |
| **认证** | OAuth2 + 本地登录 | 双重认证模式 |
| **代理池** | 免费代理池 + 隧道代理 | 反爬 IP 轮换 |

## 六、数据流

### 6.1 爬取流程

```
用户创建任务 → 保存到 sp_tasks
     ↓
启动任务 → BaseCrawler.start()
     ↓
Playwright 打开浏览器 → 搜索页 → 提取职位列表
     ↓
详情页逐个抓取 → 解析 → 写入 CSV + sp_jobs
     ↓
WebSocket 实时推送进度 → 前端更新进度条
     ↓
完成 → sp_csv_files 记录文件 → 可进行 AI 增强
```

### 6.2 AI 增强流程

```
爬取完成 → 触发 enrich/:taskId
     ↓
读取 sp_jobs 原始数据 → 调用 LLM
     ↓
并行处理每条职位 → 标准化薪资/技能/行业/学历
     ↓
写入 sp_job_enrichments → WebSocket 通知完成
```

### 6.3 RAG 语义搜索流程

```
爬取完成 → 触发 index/:taskId
     ↓
读取职位数据 → 拼接文本 → 调用 Embedding API
     ↓
生成 768 维向量 → 存入 sp_job_embeddings
     ↓
搜索时 → Embed 查询文本 → 向量相似度计算 → 返回 Top-K
```

## 七、数据库连接池

- **连接池大小**：最大 50 连接
- **空闲超时**：30 秒
- **连接超时**：5 秒
- **时区**：Asia/Shanghai（北京时区）
- **Schema**：`liangwenqing`
- **TIMESTAMP 处理**：OID 1114/1184 重写为纯字符串，去除毫秒和时区后缀

## 八、前端数据流

```
Vue Component → API 函数 (api/*.ts) → Axios 实例
     ↓
/api/* → Vite Proxy (开发) / Nginx (生产)
     ↓
Express Route → Controller → Service → pg Pool → PostgreSQL
     ↓
JSON Response → ApiResponse<T> 类型 → 组件状态更新
```

## 九、实时通信

Socket.IO 服务器在 `app.ts` 中创建，支持以下事件：

| 事件 | 方向 | 说明 |
|------|------|------|
| `task:progress` | S→C | 爬虫进度更新 |
| `task:log` | S→C | 爬虫日志推送 |
| `task:status` | S→C | 任务状态变更 |
| `enrichment:progress` | S→C | AI 增强进度 |
| `insights:completed` | S→C | 洞察报告完成 |
| `subscribe:task` | C→S | 客户端订阅任务 |
| `unsubscribe:task` | C→S | 取消订阅 |
