## 二、业务表详细结构

### 2.1 sp_tasks — 爬虫任务

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID 唯一标识 |
| `name` | VARCHAR(500) | 任务名称 |
| `source` | VARCHAR(50) | 数据源 `zhilian` / `job51` |
| `config` | JSONB | 任务配置（关键词、城市、页数、并发等） |
| `status` | VARCHAR(20) | pending / running / paused / completed / failed |
| `progress` | INTEGER | 进度百分比 0–100 |
| `total` | INTEGER | 总职位数估计 |
| `current` | INTEGER | 当前已抓取数 |
| `record_count` | INTEGER | 最终记录数 |
| `error_count` | INTEGER | 错误计数 |
| `error_message` | TEXT | 最近错误信息 |
| `csv_path` | TEXT | 导出 CSV 路径 |
| `start_time` | TIMESTAMP | 开始时间 |
| `end_time` | TIMESTAMP | 结束时间 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 2.2 sp_csv_files — CSV 文件

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) FK → sp_tasks | 关联任务 |
| `filename` | VARCHAR(500) | 文件名 |
| `filepath` | TEXT | 完整路径 |
| `file_size` | BIGINT | 文件大小（字节） |
| `record_count` | INTEGER | 记录数 |
| `source` | VARCHAR(50) | 数据源 |
| `created_at` | TIMESTAMP | 创建时间 |

### 2.3 sp_jobs — 原始职位数据

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) FK → sp_tasks | 关联任务 |
| `job_id` | VARCHAR(255) | 原始职位 ID |
| `data_source` | VARCHAR(50) | 数据源 |
| `company_name` | VARCHAR(500) | 公司名称 |
| `job_name` | VARCHAR(500) | 职位名称 |
| `work_city` | VARCHAR(100) | 工作城市 |
| `salary_range` | VARCHAR(100) | 原始薪资文本 |
| `education` | VARCHAR(50) | 学历要求 |
| `work_experience` | VARCHAR(100) | 经验要求 |
| `job_category` | VARCHAR(200) | 职位类别 |
| `raw_data` | JSONB | 完整原始数据 |
| `created_at` | TIMESTAMP | 创建时间 |

**唯一约束**：`UNIQUE(task_id, job_id)`

### 2.4 sp_llm_config — LLM 配置

| 字段 | 类型 | 说明 |
|------|------|------|

**支持的 provider**：`openai`, `anthropic`, `ollama`, `deepseek`, `zhipu`, `qwen`, `baidu`, `bytedance`, `moonshot`

### 2.9 sp_resumes — 简历结构化解析

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `original_filename` | VARCHAR(500) | 原始文件名 |
| `file_hash` | VARCHAR(64) | 文件 SHA-256 哈希（去重） |
| `raw_text` | TEXT | 简历原始文本 |
| `name` | VARCHAR(100) | 姓名 |
| `email` | VARCHAR(200) | 邮箱 |
| `phone` | VARCHAR(50) | 手机号 |
| `education_level` | VARCHAR(20) | 学历（高中/大专/本科/硕士/博士） |
| `school` | VARCHAR(200) | 毕业院校 |
| `major` | VARCHAR(200) | 专业 |
| `graduation_year` | INTEGER | 毕业年份 |
| `work_years` | INTEGER | 工作年限 |
| `skills` | JSONB | 技能列表 |
| `skill_levels` | JSONB | 技能熟练度映射 |
| `desired_position` | VARCHAR(200) | 期望岗位 |
| `desired_city` | VARCHAR(100) | 期望城市 |
| `desired_salary_min` | INTEGER | 期望月薪下限 |
| `desired_salary_max` | INTEGER | 期望月薪上限 |
| `job_type` | VARCHAR(20) | 工作类型（全职/兼职/实习） |
| `projects` | JSONB | 项目经验数组 |
| `certifications` | JSONB | 证书列表 |
| `languages` | JSONB | 语言能力数组 |
| `self_evaluation` | TEXT | 自我评价 |
| `parse_confidence` | REAL | LLM 解析置信度 0-1 |
| `parsed_by_model` | VARCHAR(100) | 解析所用模型 |
| `embedding` | vector(768) | 语义向量 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**唯一索引**：`idx_resumes_file_hash ON sp_resumes(file_hash)` — 根据文件哈希防止重复导入。
**依赖**：pgvector 扩展可用时含 `embedding` 列，否则省略。

### 2.11 sp_screening_results — 简历筛选结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `resume_id` | INT FK → sp_resumes ON DELETE SET NULL | 简历 ID |
| `internal_job_id` | INT FK → sp_internal_jobs ON DELETE SET NULL | 内部岗位 ID |
| `resume_name` | VARCHAR(200) | 简历名称（冗余，方便历史查询） |
| `internal_job_title` | VARCHAR(300) | 岗位名称（冗余） |
| `department` | VARCHAR(200) | 部门（冗余） |
| `total_score` | REAL | 综合得分 |
| `recommendation` | VARCHAR(20) | 推荐等级（strong/moderate/weak/rejected） |
| `hard_rules_passed` | BOOLEAN | 硬性规则是否通过 |
| `education_passed` | BOOLEAN | 学历是否达标 |
| `experience_passed` | BOOLEAN | 经验是否达标 |
| `skills_passed` | BOOLEAN | 技能是否达标 |
| `similarity` | REAL | 语义相似度百分比 |
| `skill_bonus` | REAL | 技能加分 |
| `score_breakdown` | JSONB | 评分明细（hardRuleScore/similarityScore/skillBonus） |
| `full_result` | JSONB | 完整匹配结果快照 |
| `created_by` | VARCHAR(100) | 操作人 |
| `created_at` | TIMESTAMP | 创建时间 |

**唯一约束**：`UNIQUE(resume_id, internal_job_id)` — 同一简历对同一岗位只保留最新一条。
**索引**：`resume_id`、`internal_job_id`、`created_at DESC`

```
sp_users ──< sp_user_roles >── sp_roles ──< sp_role_permissions >── sp_permissions
```
