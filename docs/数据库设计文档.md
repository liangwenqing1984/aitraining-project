## 二、业务表详细结构

### 2.1 sp_tasks — 爬虫任务

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID 唯一标识 |
| `name` | VARCHAR(500) | 任务名称 |
| `source` | VARCHAR(50) | 数据源 `zhilian` / `job51` |
| `config` | JSONB | 任务配置（关键词、城市、页数、并发等） |
| `status` | VARCHAR(20) | pending / running / paused / completed / failed |
| `progress` | INTEGER | 进度百分比 0–100 |
| `total` | INTEGER | 总职位数估计 |
| `current` | INTEGER | 当前已抓取数 |
| `record_count` | INTEGER | 最终记录数 |
| `error_count` | INTEGER | 错误计数 |
| `error_message` | TEXT | 最近错误信息 |
| `csv_path` | TEXT | 导出 CSV 路径 |
| `start_time` | TIMESTAMP | 开始时间 |
| `end_time` | TIMESTAMP | 结束时间 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 2.2 sp_csv_files — CSV 文件

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) FK → sp_tasks | 关联任务 |
| `filename` | VARCHAR(500) | 文件名 |
| `filepath` | TEXT | 完整路径 |
| `file_size` | BIGINT | 文件大小（字节） |
| `record_count` | INTEGER | 记录数 |
| `source` | VARCHAR(50) | 数据源 |
| `created_at` | TIMESTAMP | 创建时间 |

### 2.3 sp_jobs — 原始职位数据

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) FK → sp_tasks | 关联任务 |
| `job_id` | VARCHAR(255) | 原始职位 ID |
| `data_source` | VARCHAR(50) | 数据源 |
| `company_name` | VARCHAR(500) | 公司名称 |
| `job_name` | VARCHAR(500) | 职位名称 |
| `work_city` | VARCHAR(100) | 工作城市 |
| `salary_range` | VARCHAR(100) | 原始薪资文本 |
| `education` | VARCHAR(50) | 学历要求 |
| `work_experience` | VARCHAR(100) | 经验要求 |
| `job_category` | VARCHAR(200) | 职位类别 |
| `raw_data` | JSONB | 完整原始数据 |
| `created_at` | TIMESTAMP | 创建时间 |

**唯一约束**：`UNIQUE(task_id, job_id)`

### 2.4 sp_llm_config — LLM 配置

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `provider` | VARCHAR(50) | 提供商标识 |
| `model_name` | VARCHAR(100) | 模型名称 |
| `api_key_encrypted` | TEXT | 加密 API Key |
| `base_url` | VARCHAR(255) | API 端点 |
| `is_active` | BOOLEAN | 启用状态 |
| `task_routing` | JSONB | 分配任务 `["enrichment","insights"]` |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**支持的 provider**：`openai`, `anthropic`, `ollama`, `deepseek`, `zhipu`, `qwen`, `baidu`, `bytedance`, `moonshot`

### 2.5 sp_job_enrichments — AI 增强结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) FK | 关联任务 |
| `job_id` | VARCHAR(255) | 职位 ID |
| `salary_monthly_min` | INTEGER | 月薪下限 |
| `salary_monthly_max` | INTEGER | 月薪上限 |
| `salary_annual_estimate` | INTEGER | 估算年薪 |
| `job_category_l1` | VARCHAR(100) | 一级分类 |
| `job_category_l2` | VARCHAR(100) | 二级分类 |
| `company_industry` | VARCHAR(100) | 公司行业 |
| `key_skills` | JSONB | 关键技能列表 |
| `required_skills` | JSONB | 必备技能 |
| `preferred_skills` | JSONB | 加分技能 |
| `education_normalized` | VARCHAR(20) | 标准化后学历 |
| `experience_years_min` | INTEGER | 经验年数下限 |
| `experience_years_max` | INTEGER | 经验年数上限 |
| `benefits` | JSONB | 福利列表 |
| `work_mode` | VARCHAR(20) | 办公模式 |
| `model_used` | VARCHAR(100) | 使用的模型 |
| `enriched_at` | TIMESTAMP | 增强时间 |

**唯一约束**：`UNIQUE(task_id, job_id)`

### 2.6 sp_market_reports — 市场洞察报告

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `file_id` | VARCHAR(255) FK | 关联 CSV 文件 |
| `task_id` | VARCHAR(255) | 关联任务 |
| `report_type` | VARCHAR(50) | 报告类型 |
| `title` | VARCHAR(500) | 报告标题 |
| `content` | TEXT | Markdown 正文 |
| `summary` | TEXT | 摘要 |
| `charts_config` | JSONB | ECharts 图表配置 |
| `model_used` | VARCHAR(100) | 使用的模型 |
| `created_at` | TIMESTAMP | 生成时间 |

### 2.7 sp_saved_queries — NL 查询历史

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `task_id` | VARCHAR(255) | 关联任务（可选） |
| `user_query` | TEXT | 用户原始问题 |
| `generated_sql` | TEXT | AI 生成的 SQL |
| `result_summary` | TEXT | 结果摘要 |
| `result_data` | JSONB | 结果数据 |
| `result_count` | INTEGER | 结果数量 |
| `model_used` | VARCHAR(100) | 使用的模型 |
| `created_at` | TIMESTAMP | 查询时间 |

### 2.8 sp_job_embeddings — 职位向量（pgvector）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR(255) PK | UUID |
| `job_id` | VARCHAR(255) | 职位 ID |
| `task_id` | VARCHAR(255) FK | 关联任务 |
| `text_content` | TEXT | 原文（用于生成向量） |
| `embedding` | vector(768) | 768 维向量 |
| `job_name` | VARCHAR(500) | 职位名称 |
| `job_category_l1` | VARCHAR(100) | 一级分类 |
| `job_category_l2` | VARCHAR(100) | 二级分类 |
| `company_name` | VARCHAR(500) | 公司名称 |
| `company_industry` | VARCHAR(100) | 公司行业 |
| `work_city` | VARCHAR(100) | 工作城市 |
| `salary_monthly_min` | INTEGER | 月薪下限 |
| `salary_monthly_max` | INTEGER | 月薪上限 |
| `key_skills` | JSONB | 关键技能 |
| `source_metadata` | JSONB | 元数据 |
| `created_at` | TIMESTAMP | 创建时间 |

**唯一约束**：`UNIQUE(task_id, job_id)`
**依赖**：需要 pgvector 扩展，不可用时跳过建表。

### 2.9 sp_doc_embeddings — 文档向量（pgvector）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `section_id` | VARCHAR(100) | 章节/文件标识 |
| `section_title` | VARCHAR(200) | 标题/文件名 |
| `chunk_index` | INT DEFAULT 0 | 片段序号 |
| `text_content` | TEXT NOT NULL | 原文片段 |
| `embedding` | vector(768) | 768 维向量 |
| `source_type` | VARCHAR(50) | 来源类型（doc_section/user_doc/diagnostic 等） |
| `file_path` | VARCHAR(1000) | 源文件路径 |
| `created_at` | TIMESTAMP | 创建时间 |

**唯一约束**：`UNIQUE(section_id, chunk_index)`
**依赖**：需要 pgvector 扩展。

### 2.10 sp_chat_sessions — AI 对话会话

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `title` | VARCHAR(200) | 会话标题，默认"新对话" |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 2.11 sp_chat_messages — 对话消息

| 字段 | 类型 | 说明 |

| `id` | SERIAL PK | 自增 ID |

| `role` | VARCHAR(20) | user / assistant |
| `content` | TEXT NOT NULL | 消息内容 |

### 2.12 sp_training_jobs — 模型训练任务

| 字段 | 类型 | 说明 |

| `dataset_path` | TEXT | 训练数据 JSONL 路径 |

| `log` | TEXT | 训练日志 |
| `started_at` | TIMESTAMP | 开始时间 |
| `finished_at` | TIMESTAMP | 完成时间 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

## 三、RBAC 表详细结构

### 3.1 sp_users — 系统用户

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `username` | VARCHAR(100) UNIQUE | 用户名 |
| `password_hash` | VARCHAR(255) | bcrypt 密码哈希 |
| `real_name` | VARCHAR(100) | 真实姓名 |
| `email` | VARCHAR(200) | 邮箱 |
| `phone` | VARCHAR(50) | 手机号 |
| `oauth2_user_id` | VARCHAR(255) | OAuth2 关联 ID |
| `status` | BOOLEAN DEFAULT true | 启用/禁用 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 3.2 sp_roles — 角色

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `name` | VARCHAR(100) | 角色名称 |
| `code` | VARCHAR(100) UNIQUE | 唯一编码（如 `admin`） |
| `description` | VARCHAR(500) | 描述 |
| `status` | BOOLEAN DEFAULT true | 启用/禁用 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 3.3 sp_permissions — 权限

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `name` | VARCHAR(100) | 权限名称 |

| `resource` | VARCHAR(100) | 资源标识 |
| `action` | VARCHAR(100) | 操作（create/read/update/delete） |
| `description` | VARCHAR(500) | 描述 |
| `created_at` | TIMESTAMP | 创建时间 |

### 3.4 sp_menus — 菜单

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | SERIAL PK | 自增 ID |
| `name` | VARCHAR(100) | 菜单名称 |
| `path` | VARCHAR(255) | 前端路由路径 |
| `icon` | VARCHAR(100) | 图标名称（Element Plus 图标） |
| `parent_id` | INT FK → sp_menus.id | 父菜单 ID（树形结构） |
| `sort_order` | INT DEFAULT 0 | 排序 |
| `component` | VARCHAR(255) | 组件路径 |
| `hidden` | BOOLEAN DEFAULT false | 是否隐藏 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

### 3.5 sp_user_roles — 用户-角色关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `user_id` | INT FK → sp_users ON DELETE CASCADE | 用户 ID |
| `role_id` | INT FK → sp_roles ON DELETE CASCADE | 角色 ID |
| **PRIMARY KEY** | (user_id, role_id) | |

### 3.6 sp_role_permissions — 角色-权限关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `role_id` | INT FK → sp_roles ON DELETE CASCADE | 角色 ID |
| `permission_id` | INT FK → sp_permissions ON DELETE CASCADE | 权限 ID |
| **PRIMARY KEY** | (role_id, permission_id) | |

### 3.7 sp_role_menus — 角色-菜单关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `role_id` | INT FK → sp_roles ON DELETE CASCADE | 角色 ID |
| `menu_id` | INT FK → sp_menus ON DELETE CASCADE | 菜单 ID |
| **PRIMARY KEY** | (role_id, menu_id) | |

## 四、ER 关系图

```
sp_users ──< sp_user_roles >── sp_roles ──< sp_role_permissions >── sp_permissions
                                        └──< sp_role_menus >────── sp_menus (自引用树)

sp_tasks ──< sp_csv_files
         ──< sp_jobs ──< sp_job_enrichments
         ──< sp_job_embeddings (pgvector)
         ──< sp_saved_queries
         ──< sp_market_reports

sp_chat_sessions ──< sp_chat_messages

sp_doc_embeddings (pgvector) — 文档向量独立索引
```

## 五、索引建议

| 表 | 索引 | 用途 |
|------|------|------|
| `sp_tasks` | `status` | 按状态筛选 |
| `sp_tasks` | `created_at DESC` | 时间排序 |
| `sp_jobs` | `(task_id, job_id)` | 唯一约束 + 查询 |
| `sp_job_enrichments` | `(task_id, job_id)` | 唯一约束 + 查询 |
| `sp_job_embeddings` | `(task_id, job_id)` | 唯一约束 |
| `sp_job_embeddings` | `embedding` (IVFFlat) | 向量相似度搜索 |
| `sp_doc_embeddings` | `(section_id, chunk_index)` | 唯一约束 |
| `sp_doc_embeddings` | `source_type` | 按类型筛选 |
| `sp_chat_sessions` | `updated_at DESC` | 会话列表排序 |
| `sp_chat_messages` | `session_id` | 按会话查询消息 |
| `sp_training_jobs` | `status` | 按状态筛选 |
| `sp_users` | `username` | 登录查询 |
| `sp_roles` | `code` | 唯一约束 |
| `sp_permissions` | `(resource, action)` | 权限查询 |
| `sp_menus` | `parent_id` | 树形查询 |

## 六、初始化数据

`seedService.ts` 在数据库初始化时自动填充：

- **默认角色**：admin（超级管理员）、operator（运营人员）
- **默认权限**：user/role/permission/menu/task/file 的 CRUD 权限（20+ 条）
- **默认菜单**：10 个顶级菜单 + 7 个系统管理子菜单 + 2 个系统帮助子菜单
- **默认用户**：admin、user、test（密码均为默认值）
