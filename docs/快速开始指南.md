# 快速开始指南

## 一、环境要求

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | ≥ 18.x | 推荐 20 LTS |
| npm | ≥ 9.x | 随 Node.js 安装 |
| PostgreSQL | 16+ | 含 pgvector 扩展 |
| Ollama | (可选) | 本地 LLM 推理 |
| Git | ≥ 2.x | 版本控制 |

## 二、克隆项目

```bash
git clone <仓库地址> aitraining
cd aitraining
```

## 三、后端启动

### 3.1 安装依赖

```bash
cd code/backend
npm install
```

### 3.2 配置数据库连接

编辑 `code/backend/src/config/database.ts`：

```typescript
const pool = new Pool({
  host: '10.1.1.113',   // 数据库地址
  port: 7300,            // 数据库端口
  database: 'training_exercises',
  user: 'liangwenqing',
  password: 'liangwenqing',
  max: 50,               // 最大连接数
});
```

### 3.3 配置 OAuth2（可选）

编辑 `code/backend/.env`：

```
OAUTH2_CLIENT_ID=your_client_id
OAUTH2_CLIENT_SECRET=your_client_secret
OAUTH2_AUTHORIZE_URL=https://sso.example.com/authorize
OAUTH2_TOKEN_URL=https://sso.example.com/token
OAUTH2_USERINFO_URL=https://sso.example.com/userinfo
```

### 3.4 启动后端

```bash
npm run dev
# 或使用批处理脚本
cd ../..
start-dev.bat
```

后端运行在 `http://localhost:3001`，启动时自动初始化数据库表。

## 四、前端启动

### 4.1 安装依赖

```bash
cd code/frontend
npm install
```

### 4.2 启动开发服务器

```bash
npm run dev
```

前端运行在 `http://localhost:3002`，API 请求通过 Vite 代理转发到 `localhost:3001`。

## 五、验证安装

1. 打开浏览器访问 `http://localhost:3002`
2. 应看到登录页面
3. 使用默认管理员账号登录：
   - 用户名：`admin`
   - 密码：`Admin@admin123`
4. 登录成功后进入首页仪表盘

## 七、可选配置

### 7.1 安装 Ollama（本地模型）

```bash
# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows: 从 ollama.com 下载安装包

# 拉取模型
ollama pull qwen3:14b
ollama pull qwen3:4b

# 验证
ollama list
```

Ollama 默认运行在 `http://localhost:11434`。

### 7.2 配置 pgvector

```sql
-- 在 PostgreSQL 服务器上执行
CREATE EXTENSION IF NOT EXISTS vector;
```

如果 pgvector 不可用，系统会自动跳过向量表创建，RAG 语义搜索功能将禁用。

## 八、常见问题

### Q1: 前端启动报 "Cannot find module '@element-plus/icons-vue'"

```bash
cd code/frontend && npm install
```

### Q2: 后端报数据库连接超时

检查 `database.ts` 中的数据库地址、端口、用户名密码是否正确。

### Q3: 爬虫任务无法启动

确认 Playwright 浏览器已安装：
```bash
npx playwright install chromium
```

### Q4: Ollama 模型列表为空

1. 确认 Ollama 服务已启动
2. 确认已拉取模型：`ollama list`
3. 前端会自动显示 Ollama 部署的模型

### Q5: RAG 语义搜素不可用

检查 pgvector 扩展是否安装成功，查看后端启动日志中是否有 `✅ pgvector 扩展已就绪`。
