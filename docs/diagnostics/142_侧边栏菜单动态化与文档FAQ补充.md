# 侧边栏菜单动态化与文档 FAQ 补充

## 概述

本次变更包含三项：侧边栏菜单从硬编码改为 API 动态获取（修复菜单管理设置不生效问题）、数据采集文档新增常见问题解答、数据库备份脚本。

## 一、侧边栏菜单 API 动态化

### 问题
用户在菜单管理页面设置"关于"菜单隐藏、将"文档"改名为"帮助文档"，但侧边栏未生效——菜单仍然是硬编码的，完全不读取数据库。

### 实现
`MainLayout.vue` 菜单改为 `onMounted` 时从 `GET /api/menus/tree` 动态获取：

- 全量导入 `@element-plus/icons-vue` 建立 icon 名称→组件实例映射表
- `buildMenuItems()` 递归转换 API 菜单树为侧边栏格式，过滤 `hidden: true` 的菜单
- 菜单标题使用数据库中的 `name` 字段，确保改名生效
- 捕获异常回退，API 失败时不阻塞页面渲染

## 二、数据采集文档 FAQ

### 需求
在文档页数据采集章节补充常见反爬技术概念解答。

### 新增问答

| 问题 | 内容 |
|------|------|
| "硬编码签名识别"和"AI 驱动页面分类"分别指什么？ | 双重检测机制：硬编码关键词快速初筛 + LLM 语义分析精准确认 |
| CAPTCHA 是什么？ | 自动图灵测试，三种反爬形式对照表 + 系统应对流程 |
| JS 挑战（静默验证）是什么？ | 浏览器后台静默执行混淆 JS 生成 token，用户无感知 |
