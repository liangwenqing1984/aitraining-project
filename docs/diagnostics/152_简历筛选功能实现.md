# 简历筛选功能实现

## 概述

在「语义搜索」下新增「简历筛选」子菜单，实现简历文本向量化→职位匹配→打分排序的完整流程。同时将「语义搜索」从叶子菜单重构为父级菜单（下设「职位搜索」和「简历筛选」）。

---

## 一、菜单结构重构

### 需求/问题
原有「语义搜索」为独立叶子菜单。简历筛选功能需要挂在语义搜索下作为子菜单，两者共享 RAG 向量基础设施。

### 实现
将「语义搜索」改为父菜单（清空 path），下设两个子菜单：

**seedService.ts** — 种子数据创建流程调整：
- 前 7 个顶级菜单保持不变
- 第 8 项「语义搜索」从叶子改为 `parentId=NULL, path=NULL` 的父节点
- 创建「职位搜索」(path=/rag) 和「简历筛选」(path=/rag/resume) 作为子节点
- 管理员角色 `allMenuIds` 增加 `ragMenu.id` 和 `ragChildIds`

**database.ts** — 存量数据库迁移：
- `UPDATE sp_menus SET path = NULL WHERE name = '语义搜索' AND path IS NOT NULL` 将已存在的叶子改父节点
- `INSERT` 两个子菜单，使用 `NOT EXISTS` 防重复

**MainLayout.vue** — defaultMenuItems 兜底菜单同步更新

**router/index.ts** — 新增 `/rag/resume` 路由，`/rag` 路由标题改为「职位搜索」

---

## 二、简历匹配 API

### 需求/问题
接收简历文本，向量化后与职位向量库做余弦相似度匹配，返回排序后的职位列表。

### 实现
**ragController.ts** — 新增 `matchResume` 函数：
- 接收 `{ resumeText, limit=20, minSimilarity=0.3 }`
- 调用 `generateEmbedding()` 生成简历语义向量
- 使用 pgvector `<=>` 余弦距离算子搜索 `sp_job_embeddings`
- 返回匹配职位列表，每条含 `similarity` 分数

**ragRoutes.ts** — 注册 `POST /resume/match`

### 关键代码
```typescript
1 - (je.embedding <=> ?::vector) AS similarity
```
占位符顺序为 `vectorStr, minSimilarity, vectorStr, limit`，向量值在 SQL 中引用两次（WHERE + ORDER BY）。

## 三、简历筛选前端页面

### 需求/问题
提供简洁的简历输入界面，展示匹配结果。

### 实现
**ResumeScreening.vue** — 左右双栏布局：
- 左栏：Textarea 输入简历文本 + `.txt` 文件上传（FileReader 客户端读取）+ 相似度阈值/返回数量调节
- 右栏：匹配结果卡片列表（职位名、公司、分类标签、相似度百分比、内容摘要）
- 底部提示区说明匹配原理

**api/llm.ts** — 新增 `matchResume()` 函数，POST `/rag/resume/match`
