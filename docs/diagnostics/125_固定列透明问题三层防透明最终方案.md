# 125 — 固定列透明问题三层防透明最终方案

## 问题

多次 CSS 修复后任务列表固定列（操作列）仍然透明，导致"创建时间"列内容穿透叠加显示。同时操作列按钮自动换行。

## 根因

1. **CSS 特异性不足**：`.el-table .el-table__fixed-right` 与 `.task-table .el-table__fixed-right` 特异性相同（0,2,0），加载顺序决定优先级，不可靠
2. **`background` vs `background-color` 覆盖差异**：Element Plus 内部可能使用其中一种，单写一种可能被另一种覆盖
3. **操作列 `flex-wrap: wrap`**：按钮多时换行，但 420px 列宽足够容纳所有按钮单行显示

## 修复：三层防透明

### 第一层：全局 CSS（style.css）
- 选择器加 `body` 前缀 → 特异性从 0,2,0 提升到 0,4,0+
- `background` + `background-color` 双写

### 第二层：组件非 scoped CSS（crawler/Index.vue）
- 同样 `body` 前缀 + 双写
- 新增 `.ops-cell` 类选择器

### 第三层：内联 style（el-table-column 属性）
```html
<el-table-column cell-class-name="ops-cell"
  :cell-style="{ background: '#fafafa' }"
  :header-cell-style="{ background: '#fafafa' }">
```
Element Plus 会将 cell-style 渲染为内联 style 属性，优先级最高。

### 附加：操作列 flex-wrap 改 nowrap

## 涉及文件

| 文件 | 修改 |
|------|------|
| `code/frontend/src/style.css` | 全局固定列加 `body` 前缀 + 双写 |
| `code/frontend/src/views/crawler/Index.vue` | 操作列 nowrap + cell-style 内联 + CSS body 前缀双写 |
