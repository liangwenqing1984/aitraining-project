# 智联招聘公司性质字段修复 — 融资阶段误用为企业性质

## 日期

2026-05-07

## 问题

智联招聘爬取结果中 `公司性质`（companyNature）字段内容不正确，出现"未融资"、"A轮"等融资阶段值，而非"民营企业"、"国营企业"等企业性质分类。

## 根因分析

### 根因 1：API 详情页错误使用 `financingStageName`（主要）

`parseApiResponse()` 中第 2064 行：

```typescript
companyNature: comp?.financingStageName || '',
```

`financingStageName` 是融资阶段字段，取值范围为：
- 未融资、天使轮、A轮、B轮、C轮、D轮、已上市、不需要融资 等

这些是**融资状态**，不是企业性质（民营/国营/外企）。一旦列表页 tag 匹配失败，就会回退到这个错误值。

### 根因 2：HTML 详情页 `.company-info__desc` 格式歧义

两个 `pageEvaluate` 块中，解析 `.company-info__desc` 元素文本：
- `民营 · 100-499人 · 互联网/电子商务` → parts[0] = "民营" ✓（企业性质）
- `未融资 · 500-999人 · 计算机软件` → parts[0] = "未融资" ✗（融资阶段）

Zhilian HTML 中该元素第一个部分可能是企业性质或融资阶段，取决于该公司是否有融资记录。

## 修复方案

### 1. API 路径（`parseApiResponse`，第 2064 行）

```diff
- companyNature: comp?.financingStageName || '',
+ companyNature: '',  // 企业性质由列表页 .joblist-box__item-tag 提取，API 无对应字段
```

API 返回的 `detailedCompany` 中没有企业性质专门字段，直接留空，交列表页 tag 提取。

### 2. HTML 详情页（2 处 `pageEvaluate`，约第 2486/2860 行）

在浏览器端 JS 中增加融资阶段过滤：

```typescript
const financingKeywords = ['未融资', 'A轮', 'B轮', 'C轮', 'D轮', '天使轮', 
  'Pre-A', 'Pre-IPO', '已上市', '不需要融资', '种子轮', '战略投资', 'IPO上市', '新三板'];
const isFinancing = financingKeywords.some(kw => parts[0].includes(kw));
result.companyNature = isFinancing ? '' : parts[0];
```

### 数据流

```
列表页 → tag 匹配 ['民营','国企','外企','合资','股份制','上市公司','事业单位']
       → basicInfo.companyNature（优先使用）

详情页 API → parseApiResponse → companyNature = ''（不再污染）
详情页 HTML → pageEvaluate → 过滤融资阶段 → companyNature = 真正的企业性质或空

最终: basicInfo.companyNature || detail.companyNature || ''
```
