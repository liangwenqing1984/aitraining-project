# 任务日志噪音与稳定性优化

日期: 2026-05-06 | 分支: `with_ip_proxy_pool` | 来源: 任务 `8995daf4` 日志分析

## 背景

分析任务 `8995daf4-0954-4483-8629-9233bb0580a5`（51job，销售×北京，maxPages=1，concurrency=3）的 175 行日志，发现 3 个结构性问题但无数据重复。

## 问题 1：axios 代理失败日志噪音（80行 → ~5行）

### 现象

20 条职位每条输出相同的 4 行：

```
Direct returned JS-obfuscated page (26913B), need browser to decrypt
Proxy 118.178.235.103:80 request failed: Request failed with status code 404
Proxy 118.178.235.103:80 request failed: Request failed with status code 404
axios detail failed: PROXY_EXHAUSTED: ..., falling back to browser
```

4行 × 20条 = 80 行无意义重复日志，占日志总量 70%，严重干扰问题排查。

### 根因

- `jobs.51job.com` 旧版页面是 JS 混淆保护页面，axios 无法解密 → 每次必然触发混淆检测
- 免费代理池对 51job 域名全部返回 404，但每次仍逐个尝试
- 没有任何去重/抑制机制

### 修复

| 变更 | 说明 |
|------|------|
| `jsObfuscatedLogCount` 计数器 | 前 2 次正常输出，第 3 次起合并为一条汇总，后续不再逐条报告 |
| `deadProxyCache: Set<string>` 黑名单 | 代理首次返回 404/ECONNRESET/ETIMEDOUT 后加入黑名单，后续职位跳过不试 |

**涉及文件**: [job51.ts](../../code/backend/src/services/crawler/job51.ts)

## 问题 2：浏览器崩溃导致详情页数据降级

### 现象

```
Line 141: 详情页第1次尝试失败(将重试): Navigating frame was detached
Line 143: [17/20] ⚠️ 浏览器已断开，使用列表数据
Line 146: [ERROR] ❌ 浏览器连接已断开，无法重试
```

职位 17-20 全部回退到 `generateBasicJob()`（仅搜索 API 基础字段），丢失详情页富文本（职位描述、公司介绍等）。

### 根因

3 个并发 tab 同时加载 `jobs.51job.com` 旧版页面（每个需 Chrome 执行 26KB JS 解密 → 渲染 98KB DOM），Chrome 进程过载导致页面脱离（"Navigating frame was detached"），随后整个浏览器断开连接。

### 修复

`maxConcurrency` 上限从 `3` 降为 `2`。2 并发在保持吞吐的同时避免 Chrome 过载崩溃。

**涉及文件**: [job51.ts:622](../../code/backend/src/services/crawler/job51.ts#L622)

## 问题 3：进度推送重复触发

### 现象

```
131: 时间间隔(23.4s), totalRecords=13 → progress: 52%
134: 数据量(15条),  totalRecords=15 → progress: 54%   ← 200ms内两次推送
```

同一批次完成窗口内触发两次 DB 写入 + 两次 WebSocket 推送。

### 根因

并发批次完成后，`Promise.allSettled` 结果在 tight loop 中逐个 yield。第一个 yield 时 `totalRecords=13`，`elapsed >= 2` 为 true（时间触发器命中）。第二个 yield 时 `totalRecords=15`，`totalRecords % 5 === 0` 为 true（取模触发器命中）。两次更新间隔 <200ms。

### 修复

`totalRecords % 5 === 0`（绝对取模）→ `(totalRecords - lastRecordCount) >= 5`（增量检测）。

增量检测确保自上次更新后累积 ≥5 条才触发，同一批次窗口内的 rapid yield 不会重复触发。

**涉及文件**: [taskService.ts:357](../../code/backend/src/services/taskService.ts#L357)

## 效果对比

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 日志噪音行数（20条职位） | ~80 行 axios 失败 | ~5 行汇总 |
| 浏览器崩溃风险 | 3并发 → 经常崩溃 | 2并发 → 降低 |
| 进度重复推送 | 每次批次完成触发 2 次 | 每次批次触发 1 次 |
| 无效代理重试 | 每条职位都重试全部代理 | 首次 404 后黑名单跳过 |
