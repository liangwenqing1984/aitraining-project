## 第一轮：日志噪音与稳定性 (来源: `8995daf4`)

### 问题 1.1 — axios 代理失败日志噪音

每条职位输出 4 行重复日志，20 条 × 4 = 80 行占日志总量 70%。

**修复**: [job51.ts](../../code/backend/src/services/crawler/job51.ts)
- `jsObfuscatedLogCount` 计数器：前 2 次正常输出，第 3 次起合并为一条汇总
- `deadProxyCache: Set<string>` 黑名单：代理首次 404/ECONNRESET/ETIMEDOUT 后加入，后续跳过

### 问题 1.2 — 浏览器崩溃导致详情页降级

3并发 tab 同时加载 JS 混淆页面导致 Chrome "Navigating frame was detached"，职位 17-20 降级为基础数据。

**修复**: [job51.ts:622](../../code/backend/src/services/crawler/job51.ts#L622)
- `maxConcurrency` 上限 `3` → `2`

### 问题 1.3 — 进度推送重复触发

时间触发器和取模触发器在同一批次窗口内同时命中，200ms 内两次 DB 写入 + WebSocket 推送。

**修复**: [taskService.ts:357](../../code/backend/src/services/taskService.ts#L357)
- `totalRecords % 5 === 0` → `(totalRecords - lastRecordCount) >= 5`（增量检测替代绝对取模）

## 第二轮：WAF 恢复死循环 (来源: `547cd605`)

### 问题 2.1 — WAF 恢复策略全部无效

reload(10s) → 去 reportType(15s) → 首页搜索(15s) 三种策略都返回 7884 字节 WAF，每轮浪费 ~40 秒。BROWSER_RESTART 换浏览器不换 IP，新浏览器碰到相同 WAF，仅等 3 秒就重试。

**修复**: [job51.ts:323-373](../../code/backend/src/services/crawler/job51.ts#L323)
- 重载(10s) → **长等待(45-90s)让 WAF 自然过期** → 重试原 URL
- 去 reportType + 首页搜索降级为"最后手段"，仅长等待失败后才尝试
- WAF 恢复结束时输出总耗时和最终 HTML 长度

**修复**: [taskService.ts:699-704](../../code/backend/src/services/taskService.ts#L699)
- BROWSER_RESTART 退避延迟：第 1 次 30s，第 2 次 60s，第 3 次 90s（上限 120s）

### 验证效果 (任务 `2d0ea63e`)

```
重载后HTML: 7884字符
⏳ 重载无效，等待 76s 让WAF自然过期...
🔄 WAF等待后HTML: 7884字符
🔄 长等待仍WAF，尝试去reportType+首页搜索最后回退...
🔄 备用URL HTML: 642072字符  ← 成功恢复
WAF恢复流程结束 (93.5s), 最终HTML: 642072字符
```

## 第三轮：axios 详情路径冗余 (来源: `2d0ea63e`)

### 问题 3.1 — PROXY_EXHAUSTED 是预期行为

免费代理对 51job 域名全返回 404，浏览器回退是正常流程，不应是 `[WARN]`。

**修复**: `warn` → `info`

### 问题 3.2 — 小页面代理未过滤

`121.40.98.50:80` 返回 785B 小页面（非 404），没有被加入黑名单，后续职位仍会重试。

**修复**: 返回 `<1000B` 的代理也加入 `deadProxyCache`

### 问题 3.3 — axios 详情页路径对 51job 永远失败

```
直连 axios → JS 混淆 26KB（无法解密）
代理 axios → 404 或 785B 小页面
两者都失败 → 走浏览器渲染
```

每条约浪费 3-5 秒，20 条 = 60-100 秒纯浪费。

**修复**: 删掉 `fetchDetailViaProxy()` 调用，51job 详情全部直连浏览器渲染。节省每任务 ~60-100 秒。
