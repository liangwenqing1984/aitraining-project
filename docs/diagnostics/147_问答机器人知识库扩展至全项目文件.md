# 问答机器人知识库扩展至全项目文件

## 概述

将问答机器人 RAG 知识库从 30 个静态 HTML 章节扩展至全项目 312+ 文件索引——包括源代码（backend/frontend）、用户文档（docs/）、诊断文档（docs/diagnostics/）、设计文档（doc/），以及 Docs.vue 中遗漏的 2 个 API 章节。

## 一、数据库变更

`sp_doc_embeddings` 表新增两列：

| 列名 | 类型 | 说明 |
|------|------|------|
| `source_type` | VARCHAR(50) | 内容来源类型（doc_section / user_doc / diagnostic / design_doc / backend_source / frontend_source） |
| `file_path` | VARCHAR(1000) | 源文件相对路径（doc_section 类型为 NULL） |

新增索引 `idx_doc_embeddings_source_type`。

## 二、新增文件源扫描器

`code/backend/src/services/docSourceScanner.ts`：
- 定义 6 种 `SourceType` 枚举 + 中文标签映射
- `scanFiles(sourceTypes?)` 使用 Node.js 内置 `fs.readdirSync({ recursive: true })` 递归扫描 5 类文件源
- 排除 `.` 开头目录、`node_modules`、`dist`
- Markdown 文件自动提取首个 `#` 标题，源代码使用相对路径作为标题

## 三、docIndexService.ts 重构

### 3.1 DOC_SECTIONS 补全
新增两个缺失章节：
- `api-analysis` — 数据分析 API（5 个端点）
- `api-dashboard` — 数据看板 API（2 个端点）

### 3.2 接口扩展
- `DocSection` 新增 `sourceType?` / `filePath?` 字段
- `DocSearchResult` 新增 `sourceType` / `filePath?` 字段

### 3.3 indexAllDocs 重构
- 新增 `sourceTypes?` 参数支持按类型增量索引
- 提取 `indexSource()` 内部辅助函数统一索引逻辑
- **Phase 1**：索引 DOC_SECTIONS（帮助文档章节）
- **Phase 2**：调用 `scanFiles()` 扫描文件源并逐文件索引

### 3.4 内容分块策略
| 类型 | 一级分割 | 二级分割 |
|------|----------|----------|
| HTML 文档 | stripHtml + splitLongText (3000字) | 句号边界 |
| Markdown | `##` 标题分割 | 超长按句号二次分割 |
| 源代码 | 双空行分割 | `export function/class/const` 边界 → 句号 |

### 3.5 搜索与统计扩展
- `searchDocs()` / `keywordSearch()` — SELECT 增加 `source_type`、`file_path`，result 映射包含新字段
- `getDocIndexStats()` — 新增 `sourceBreakdown` 按 source_type 分组统计

## 四、chatService.ts 更新

- **RAG 提示词**：从"仅根据帮助文档内容"→"可根据帮助文档/用户手册/诊断文档/设计文档/后端源代码/前端源代码回答"
- **上下文组装**：每条参考内容前加来源类型标签（如 `[后端源代码] zhilian.ts`）
- **sources 序列化**：保存 `sourceType`、`filePath` 到 sp_chat_messages.sources JSONB

## 五、前端变更

- **来源标签着色**：帮助文档默认、诊断文档 warning、后端源代码 danger、前端源代码 info
- **类型前缀**：标签内显示 `[诊断文档] · 标题` 格式
- **索引状态**：展示 `已索引 X 片段（Y 类源）`，hover 显示各类源数量明细
