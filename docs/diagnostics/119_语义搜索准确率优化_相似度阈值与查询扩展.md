# 语义搜索准确率优化 — 相似度阈值与查询扩展

## 日期

2026-05-07

## 问题现象

用户搜索"UI"，返回结果中包含"手机app测试运维"等完全无关的职位，语义匹配准确率低下。

## 根因分析

1. **硬编码低阈值**：前端 `doSearch()` 中硬编码 `minSimilarity: 0.3`，覆盖了后端默认值。`nomic-embed-text` 模型下 0.3 的相似度阈值无法有效过滤噪声。

2. **短查询信息量不足**：搜索"UI"仅 2 个字符，embedding 向量缺乏足够的语义信息，导致与无关职位的距离无法拉开。

3. **查询与索引文本域不匹配**：用户搜索的是简短关键词，而索引文本是结构化职位描述（`职位: xxx; 分类: xxx; 技能: xxx`），两者语义分布差异大。

## 修复方案

### 后端 (rag.ts)

**1. 提升默认阈值 (0.3 → 0.5)**
```typescript
// 修改前
const { limit = 10, taskId, minSimilarity = 0.3 } = options;
// 修改后
const { limit = 10, taskId, minSimilarity = 0.5 } = options;
```

**2. 查询扩展映射表**

新增 35 个常用技术术语的中文扩展映射：
```typescript
const QUERY_EXPANSION_MAP: Record<string, string> = {
  'ui': 'UI设计师 用户界面设计 交互设计 视觉设计 Figma Sketch',
  'java': 'Java开发 后端开发 Spring SpringBoot 微服务 JVM',
  '前端': '前端开发 Vue React TypeScript Web开发 JavaScript HTML CSS',
  // ... 共 35 个条目
};
```

**3. 短查询通用扩展**
- ≤10 字且不在映射表中的查询，自动追加 `招聘 职位` 领域上下文
- 扩展日志记录：`[RAG] 查询扩展: "UI" → "UI (UI设计师 用户界面设计...)"`

### 前端 (rag/Index.vue)

**4. 相似度可调滑块**
- 新增 `minSimilarity` ref，默认 0.5
- UI 滑块范围 0.3~0.9，步长 0.05
- `doSearch()` 使用用户选择的阈值替代硬编码 0.3

**5. 匹配度标签阈值上调**
- 绿色（高匹配）: >0.7 → >0.8
- 橙色（中匹配）: >0.5 → >0.6

## 涉及文件

| 文件 | 操作 |
|------|------|
| `code/backend/src/services/llm/rag.ts` | 阈值提升 + 查询扩展映射表 + expandQuery 函数 |
| `code/frontend/src/views/rag/Index.vue` | 新增相似度滑块 + 替换硬编码阈值 + 标签阈值调整 |

## 验证方法

1. 重启后端，搜索"UI"，观察日志确认查询被扩展
2. 拖动相似度滑块至 0.7+，确认仅返回高匹配结果
3. 对比修复前后相同查询的结果相关性

## 预期效果

- 短关键词搜索准确率显著提升
- 无关联位被更高阈值过滤
- 用户可根据需求自行调节精度/召回平衡
