# 语义模型训练模块实现

## 概述

新增「语义模型训练」模块，利用已爬取的岗位 JD 增强数据（`sp_job_enrichments`）构建对比学习训练对，支持通过 Python sentence-transformers 对 Embedding 模型进行岗位领域微调，并部署到 Ollama。

整体架构：TypeScript 做数据准备 → Python 做训练 → Ollama 加载部署。

---

## 一、数据库变更

### sp_training_jobs 表
在 [database.ts](code/backend/src/config/database.ts) 中新增，记录训练任务的完整生命周期：

| 字段 | 类型 | 说明 |
|------|------|------|
| name | VARCHAR(200) | 任务名称 |
| dataset_config | JSONB | 数据集配置（taskIds, strategy, filters） |

| log | TEXT | 训练日志（stdout+stderr） |

## 二、后端实现

### 训练数据构建器 — `services/llm/trainingData.ts`

- `buildTrainingDataset(config)` — 从 `sp_job_enrichments` LEFT JOIN `sp_jobs` 提取数据
- 正样本策略：同 `job_category_l2`（同一二级分类下的不同岗位）
- 负样本策略：不同 `job_category_l1` 的随机岗位
- 复用 `embeddings.ts` 的 `buildJobText()` 构建文本
- 输出 JSONL 格式：`{"anchor":"...","positive":"...","negative":"..."}`
- 保存到 `data/training/dataset_{timestamp}.jsonl`

### 训练控制器 — `controllers/trainingController.ts`

9 个 API 端点：

| 方法 | 路由 | 说明 |
|------|------|------|
| POST | `/api/training/dataset/build` | 构建训练数据集 |
| GET | `/api/training/dataset/list` | 列出已有数据集 |
| GET | `/api/training/dataset/:id/preview` | 预览前10条样本 |
| POST | `/api/training/start` | 启动训练（spawn Python子进程） |
| GET | `/api/training/status/:id` | 查询训练进度/状态/日志 |
| GET | `/api/training/list` | 分页列出训练任务 |
| DELETE | `/api/training/:id` | 删除训练任务及模型文件 |
| GET | `/api/training/models` | 列出已训练模型 |
| POST | `/api/training/models/deploy` | 部署模型到 Ollama |

- `startTraining` 异步执行，立即返回 jobId，后台 spawn Python 子进程
- 通过 `stdout` 中 `PROGRESS:{pct}` 标记解析训练进度
- `deployModel` 读取 Modelfile → 调用 Ollama `/api/create` 注册模型

### 训练路由 — `routes/trainingRoutes.ts`

在 [app.ts](code/backend/src/app.ts) 中挂载：`app.use('/api/training', trainingRoutes)`

## 三、Python 训练脚本

[scripts/train_embedding.py](code/backend/scripts/train_embedding.py)：

- 使用 `sentence-transformers` + `torch`
- 训练方法：`MultipleNegativesRankingLoss`（利用 (anchor, positive) 对，batch 内其他样本自动作负样本）
- 支持参数：`--epochs`, `--batch-size`, `--lr`, `--eval-split`
- 输出：微调模型（safetensors）+ Modelfile（Ollama 导入）+ metrics.json
- 依赖：`pip install sentence-transformers torch`

Node.js 通过 `spawn('python', [...args])` 调用，解析 stdout 的 `PROGRESS:{pct}` 更新训练进度。

## 四、前端实现

### API 模块 — `api/training.ts`

导出 9 个类型化函数：`buildDataset`, `listDatasets`, `previewDataset`, `startTraining`, `getTrainingStatus`, `listTrainingJobs`, `deleteTrainingJob`, `listModels`, `deployModel`。

### 页面 — `views/system/ModelTraining.vue`

参照 `VectorData.vue` 的 `el-tabs` 模式，分为三个 Tab：

**Tab 1: 训练数据**
- 多选已完成任务 → 选择正样本策略 → 构建数据集
- 数据集列表表格（文件名、对数、大小）
- 预览对话框：展示 Anchor / Positive / Negative 三列样本

**Tab 2: 训练任务**
- 表单：数据集 + 基座模型名 + epochs/batch_size/lr
- 训练中轮询更新进度条（每 3 秒）
- 查看日志对话框
- 删除确认

**Tab 3: 模型管理**
- 训练产出模型列表
- 部署到 Ollama：输入模型名 → 确认（带维度变更警告）
- 部署后需在「模型配置」中切换 embedding 任务指向

### 路由 + 菜单

- [router/index.ts](code/frontend/src/router/index.ts)：新增 `/system/training` → `ModelTraining.vue`
- [MainLayout.vue](code/frontend/src/layouts/MainLayout.vue)：defaultMenuItems 新增「模型训练」
