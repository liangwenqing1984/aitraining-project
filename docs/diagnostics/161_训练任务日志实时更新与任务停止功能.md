# 训练任务日志实时更新与任务停止功能

## 概述

本次修复解决模型训练模块三个核心问题：训练日志/进度不实时更新、训练任务无法中途停止、模型管理列表无法删除孤儿文件，同时修复了训练脚本的多项运行时兼容性问题。

## 一、日志实时更新

### 问题
日志仅在 Python 输出 `PROGRESS:xx` 行时才写入数据库。模型下载/加载阶段（PROGRESS:5→15）有大量 `tqdm` 进度条输出但无 PROGRESS 标记，导致前端日志始终为空，用户体验"训练没动静"。

### 修复
`trainingController.ts` 增加 2 秒定时器，有数据写入即刷新日志到 DB：

```typescript
const logTimer = setInterval(() => {
  if (logDirty) {
    db.prepare('UPDATE sp_training_jobs SET progress = $1, log = $2, updated_at = CURRENT_TIMESTAMP WHERE id = $3')
      .run(lastProgress, sanitizeLog(log), jobId);
  }
}, 2000);
```

同时增加 `sanitizeLog` 函数清理 tqdm Unicode 块字符和回车符，避免日志乱码。

## 二、训练任务停止

### 需求
运行中的训练任务无法中断，只能等待完成或失败。

### 实现
- **后端**：`runningProcesses` Map 跟踪进程 PID，`POST /api/training/:id/stop` 接口通过 `taskkill /T /F` 终止进程树并标记 `stopped` 状态
- **前端**：训练任务列表操作列增加橙色"停止"按钮（仅 `running` 状态可见）

## 三、模型管理直接删除

### 问题
模型管理 Tab 的"删除"按钮未真正执行删除，仅提示"请通过训练任务列表删除"。训练失败/中断产生的空模型目录（孤儿文件）无法清理。

### 修复
- 后端新增 `DELETE /api/training/models/:name`，直接删除模型目录（含路径穿越防护）
- 前端 `handleDeleteModel` 改为调用 API 实际删除，删除后刷新列表

## 四、训练脚本运行时兼容性修复

多项 Python 环境兼容问题逐一修复：

| 问题 | 修复 |
|---|---|
| `EmbeddingSimilarityEvaluator` 缺少 `scores` 参数 | 传入 `scores=[1.0] * len(eval_pairs)` |
| `train_embedding.py` 预下载模型时下载无用 ONNX 文件超时 | 用 `snapshot_download(ignore_patterns=["onnx/*"])` 跳过 |
| `transformers` 4.46 与 `sentence-transformers` 3.2.1 的 `num_items_in_batch` 不兼容 | 降级 `transformers` 到 4.45.2 |
| `Trainer` 缺少 `accelerate` 库 | `pip install accelerate` |
| `Trainer` 缺少 `datasets` 库 | `pip install datasets` |
| 模型需 `trust_remote_code=True` | `SentenceTransformer(trust_remote_code=True)` |

## 五、模型管理创建时间修复

`fs.statSync().ctime` 在 Windows 上为"变更时间"而非"创建时间"，改为 `birthtime` 优先，并格式化为 `YYYY-MM-DD HH:mm:ss` 字符串。
