# 问答机器人与 RAG 文档检索

## 概述

新增"问答机器人"完整功能：基于帮助文档的 RAG 智能问答，支持会话历史管理，包含后端 API + 数据库 + 前端聊天界面。

## 一、数据库新增

### 新增 3 张表

| 表名 | 说明 |
|------|------|
| `sp_doc_embeddings` | 文档向量表，存储帮助文档的 pgvector 向量化片段 |
| `sp_chat_sessions` | 聊天会话表 |
| `sp_chat_messages` | 聊天消息表（含引用来源 JSONB） |

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat/send` | 发送消息，返回 AI 回答 + 引用来源 |

### RAG 问答架构

```
用户提问 → 三层文档检索 → 构建 Prompt（文档上下文 + 用户问题）→ LLM 生成 → 返回答案 + 来源
```

**三层文档检索**：
1. pgvector 余弦相似度向量搜索（阈值 0.25）
2. 数据库 ILIKE 关键词搜索（30+ 术语映射表）
3. 内存 2-gram 中文关键词匹配（无依赖兜底）

### 中文短查询匹配优化

向量搜索对中文短查询效果不稳定。通过以下机制保证检索命中率：
- `DOC_KEYWORD_MAP`（30+ 术语映射）：常见查询词 → 文档关键词扩展
- 中文 2-gram 拆分："数据库设计" → ["数据","据库","库设","设计"] → "数据"命中"数据库表结构"标题
- 向量结果与内存结果始终合并去重，确保覆盖率

## 四、自动索引

服务启动 3 秒后自动检查文档索引状态，未索引则自动触发 `indexAllDocs()`——将 28 个帮助文档章节逐条向量化存入 `sp_doc_embeddings` 表。
