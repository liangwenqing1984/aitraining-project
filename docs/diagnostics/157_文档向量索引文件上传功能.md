# 文档向量索引——文件上传功能

## 概述

在文档向量索引管理页面新增文件上传入口，支持用户上传 `.txt` / `.md` / `.pdf` / `.docx` / `.doc` 文件，系统自动解析文本、分块、向量化并写入 `sp_doc_embeddings`，同时支持多文件批量上传（最多 20 个）。

## 一、后端文件上传与索引

### 需求/问题
此前文档向量只能通过 `POST /api/docs/index` 从预定义目录（`docs/`、`README.md`、源代码）批量索引，无法按需添加单个文档文件。

### 实现/修复

**1. Multer 配置** — `docController.ts`

新增 multer 中间件，内存存储模式，限制单文件 10MB，仅放行 `txt/md/pdf/docx/doc` 五种格式。

**2. 上传接口** — `POST /api/docs/index/file`

`docController.ts` 新增 `uploadAndIndexFile` 处理器，使用 `upload.array('files', 20)` 支持多文件。遍历每个文件：
- 中文文件名修复：`Buffer.from(originalname, 'latin1').toString('utf8')`
- 调用 `extractResumeText()` 解析文本（pdf/docx 需额外解析）
- 文本长度校验（至少 50 字符）
- 调用 `docIndexService.indexUploadedFile()` 完成分块+向量化+入库
- 返回结构化结果：`{ results, failures, totalFiles, successCount, failCount }`

**3. 索引逻辑** — `docIndexService.ts`

新增三个函数：
- `inferSourceType(fileName)` — 根据扩展名推断来源类型（统一归为 `user_doc`）
- `fileNameToSectionId(fileName)` — 生成安全的 section_id（`upload_` 前缀 + 去特殊字符）
- `indexUploadedFile(text, fileName)` — 核心流程：
  - 按 section_id 删除旧数据（覆盖上传场景）
  - 根据文件类型选择分块策略（md → `splitMarkdown`，其他 → `splitLongText`）
  - 逐块生成 embedding 并 `INSERT ... ON CONFLICT DO UPDATE`
  - 块间间隔 200ms 避免 Ollama 限流
  - 错误阈值：超过 10 个错误自动中止

**4. 路由注册** — `chatRoutes.ts`

```typescript
router.post('/docs/index/file', ...docController.uploadAndIndexFile);
```

## 二、前端上传交互

### 需求/问题
初始实现为单文件自动上传（选择即上），后续要求支持同时选择多个文件。

### 实现/修复

**1. API 层** — `api/chat.ts`

`uploadDocFile(file)` → `uploadDocFiles(files: File[])`：
- 接受文件数组，逐个 `formData.append('files', f)`（字段名与后端 `upload.array('files', 20)` 一致）
- 返回类型更新为多文件结构：`{ results[], failures[], totalFiles, successCount, failCount }`

**2. 页面交互** — `VectorData.vue`

- 新增拖拽上传区域（el-upload drag），`multiple` 多选、`auto-upload="false"`
- 选择文件后仅做大小校验（>10MB 跳过），文件累积到 `pendingFiles` 数组
- 文件列表可见，显示「开始上传（已选 N 个文件）」按钮 + 「清空」按钮
- 上传中显示 Loading 动画
- 成功后区分全成功 / 部分成功提示，自动刷新文档列表
