# 科技蓝数据大屏

## 概述

新增"数据大屏"菜单页面，采用科技蓝深色主题全屏布局，中间展示黑龙江省区域热力地图，四周环绕统计卡片和多种分析图表，支持悬停放大交互。

## 一、页面布局

### 设计
- 全屏深蓝背景 `#060e1a` + 网格纹理 + 径向光晕
- 顶部标题栏：渐变色标题 + 实时时钟
- 三栏 CSS Grid：左 300px / 中自适应 / 右 320px
- 左侧：4 指标卡片 2×2 网格 + 薪资分布柱状图 + 学历分布环形饼图
- 中间：黑龙江热力地图 + 热门技能词云
- 右侧：行业 Top10 + 经验年限分布 + 城市 Top8

### 主题色
- 青色 `#00d4ff` / 蓝色 `#1e80ff` / 紫色 `#a855f7`
- 所有 ECharts 图表统一深色配色，面板带发光边框

## 二、悬停放大交互

### 需求
鼠标移至左右两侧任一分析图表时，该图表在中间区域全高度放大展示。

### 实现
- `focusedPanel` 状态控制中间区域 `v-if`/`v-else` 切换
- `renderFocusChart(type)` 按图表类型渲染放大版（含更多数据点、更大字号和标签）
- 200ms 防抖延迟：快速切换面板不闪烁
- 焦点清除后自动重新初始化地图和词云图表
- 聚焦面板金色发光边框 + "悬停放大中"脉冲提示

## 三、大屏全屏适配

### 问题
顶部导航栏遮挡大屏内容。

### 修复
- `MainLayout.vue` 新增 `isFullScreen` 计算属性（检测 `/daping` 路由）
- 侧边栏和顶栏 `v-show="!isFullScreen"` 隐藏
- 主内容区 `.main--fullscreen` 类去除 padding 和 overflow

## 四、地图工具提示修复

### 问题
悬停地图各市时职位数显示为空。

### 根因
父容器 `.dp-col` 和 `.dp-panel` 的 `overflow: hidden` 裁剪了 ECharts tooltip 渲染层。

### 修复
- 移除面板容器 `overflow: hidden`
- 工具提示使用深色半透明背景 + 青色边框与主题一致
- 数值通过 `params.data?.value ?? params.value` 三级回退取值

## 五、数据库菜单

- 新增"数据大屏"菜单（path: `/daping`, icon: `Monitor`, sortOrder: 5）
- 种子数据同步更新，后续菜单排序号顺延
- 默认菜单兜底数组同步添加
