# 智能分析兼容51job字段名修复

## 问题

51job 任务做智能分析时，部分图表（城市分布、职位分布、企业性质）无数据。

## 根因

智能分析模块读取 CSV/Excel 文件头字段名，前端图表硬编码智联字段名查找，51job 字段名不同导致匹配失败：

| 图表 | 智联字段 | 51job字段 | 匹配结果 |
|------|---------|----------|---------|
| 城市分布 | `工作城市` | `城市` | 失败 |
| 职位分布 | `职位名称` | `岗位名称` | 失败 |
| 企业性质 | `公司性质` | `企业类型` | 失败 |

## 修复内容

### 后端 `fileController.ts`

企业性质字段查找增加51job兼容：

```typescript
let natureField = headers.find(h => h === '公司性质')
if (!natureField) natureField = headers.find(h => h === '企业类型')  // 新增
if (!natureField) natureField = headers.find(h => h.includes('性质'))
if (!natureField) natureField = headers.find(h => h.includes('企业类型'))  // 新增
```

### 前端 `analysis/Index.vue`

城市字段精确匹配增加 `'城市'`：

```typescript
let cityField = headers.find(h => h === '工作城市') || headers.find(h => h === '城市')
```

职位字段精确匹配增加 `'岗位名称'`，模糊匹配增加 `'岗位'`：

```typescript
let jobField = headers.find(h => h === '职位名称') || headers.find(h => h === '岗位名称')
// 模糊匹配
jobField = headers.find(h => (h.includes('职位') || h.includes('岗位')) && !h.includes('ID'))
```

## 涉及文件

- `code/backend/src/controllers/fileController.ts`
- `code/frontend/src/views/analysis/Index.vue`

## 验证

重启 `start-dev.bat`，使用 51job 任务做智能分析，城市分布/职位分布/企业性质图表应有数据。
