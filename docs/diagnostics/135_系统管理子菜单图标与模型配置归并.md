# 系统管理子菜单图标与模型配置归并

> 日期：2026-05-08

## 一、变更说明

### 1.1 模型配置归入系统管理

将"模型配置"从顶级菜单移入"系统管理"子菜单，统一管理类功能的入口。

**变更前**：
```
顶级菜单: 首页 / 数据采集 / 数据管理 / 智能分析 / 智能查询 /
         语义搜索 / 模型配置 / 系统管理 / 文档 / 关于
系统管理 ─
  ├── 用户管理
  ├── 角色管理
  ├── 权限管理
  └── 菜单管理
```

**变更后**：
```
顶级菜单: 首页 / 数据采集 / 数据管理 / 智能分析 / 智能查询 /
         语义搜索 / 系统管理 / 文档 / 关于
系统管理 ─
  ├── 用户管理
  ├── 角色管理
  ├── 权限管理
  ├── 菜单管理
  └── 模型配置
```

### 1.2 子菜单添加图标

5 个子菜单全部添加图标，提升视觉辨识度和导航体验。

| 子菜单 | 图标 | 图标名称 |
|--------|------|---------|
| 用户管理 | User | `User` |
| 角色管理 | UserFilled | `UserFilled` |
| 权限管理 | Lock | `Lock` |
| 菜单管理 | Menu | `Menu` |
| 模型配置 | Setting | `Setting` |

## 二、修改文件

### 2.1 前端 MainLayout.vue

**图标导入**：新增 `UserFilled`, `Lock`, `Menu` 三个图标。

**接口更新**：
```typescript
interface MenuItem {
  path?: string; title: string; icon: any;
  children?: { path: string; title: string; icon?: any }[]  // ← icon 改为可选
}
```

**菜单数据**：模型配置从顶级移入 children，所有子项加 icon。

**模板更新**：
```html
<el-menu-item ... class="menu-item-custom sub-item">
  <div class="sub-item-content">
    <el-icon v-if="child.icon" class="sub-icon">
      <component :is="child.icon" />
    </el-icon>
    <span>{{ child.title }}</span>
  </div>
</el-menu-item>
```

**CSS 新增**：
```css
.sub-item-content { display: flex; align-items: center; gap: 8px; }
.sub-icon { font-size: 16px; flex-shrink: 0; color: #9ca3af; }
.sub-item.is-active .sub-icon { color: #667eea; }
```

### 2.2 后端 seedService.ts

- 顶级菜单数组移除模型配置（sortOrder 7）
- 系统管理 sortOrder: 8 → 7
- 文档 sortOrder: 9 → 8，关于 sortOrder: 10 → 9
- 系统管理子菜单增加模型配置（sortOrder 5，icon Setting）
- 所有子菜单增加 icon 字段

### 2.3 数据库存量修复

已运行的数据库通过临时脚本直接更新：

```sql
-- 模型配置归入系统管理
UPDATE sp_menus SET parent_id = <系统管理id>, sort_order = 5, icon = 'Setting'
WHERE path = '/settings/llm' AND parent_id IS NULL;

-- 子菜单补充图标
UPDATE sp_menus SET icon = 'User'      WHERE path = '/system/users';
UPDATE sp_menus SET icon = 'UserFilled' WHERE path = '/system/roles';
UPDATE sp_menus SET icon = 'Lock'      WHERE path = '/system/permissions';
UPDATE sp_menus SET icon = 'Menu'      WHERE path = '/system/menus';

-- 排序重排
UPDATE sp_menus SET sort_order = 7 WHERE name = '系统管理' AND parent_id IS NULL;
UPDATE sp_menus SET sort_order = 8 WHERE name = '文档'     AND parent_id IS NULL;
UPDATE sp_menus SET sort_order = 9 WHERE name = '关于'     AND parent_id IS NULL;
```
