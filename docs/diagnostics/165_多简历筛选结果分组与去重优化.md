# 多简历筛选结果分组展示与去重优化

## 概述

修复上传多份简历后"开始智能筛选"结果混乱的问题，核心涉及 Vue `:key` 冲突、`totalCompared` 累加、同 ID 防重复、按简历分组展示。

## 一、Vue :key 冲突导致 DOM 渲染混乱

### 需求/问题
多份简历匹配同一岗位时，`internalJobId` 相同导致 Vue 的 `v-for` `:key` 冲突，DOM 元素被复用，结果卡片的标题/分数/标签交叉显示。

### 修复
`ResumeScreening.vue` 结果列表 `:key` 从 `item.internalJobId` 改为 `` `${item._resumeId}_${item.internalJobId}` ``，确保每条结果唯一标识。

## 二、totalCompared 被覆盖

### 需求/问题
多份简历逐份筛选时 `totalCompared = res.data.totalJobsCompared` 用 `=` 赋值，每次循环覆盖前值，提示语只显示最后一份简历的比较岗位数。

### 修复
`=` 改为 `+=`，累加所有简历的比较岗位总数。

## 三、同 ID 简历重复添加

### 需求/问题
同一份文件上传两次（或已存在的简历重复拖入），`parsedResumes` 出现两条相同 `id` 的记录，导致同一简历被重复筛选，结果列表出现完全相同的两组数据。

### 修复
`handleFileChange` 解析成功后在 push 前检查 `parsedResumes.value.some(pr => pr.id === res.data.id)`，已存在则跳过并提示用户。

## 四、多简历结果按简历分组展示

### 需求/问题
多份简历的匹配结果全部混在一个扁平列表中按分数排序，无法直观区分每条结果属于哪份简历。

### 修复
- 新增 `groupedScreeningResults` computed：按 `_resumeId` 将结果分组，每组含 `resumeName` + `results[]`
- 模板改为嵌套循环：外层遍历分组渲染蓝色标题栏（图标 + 简历名 + 匹配数），内层遍历各组结果卡片
- 移除结果卡片里重复的 `_resumeName` 标签（已在分组标题显示）
