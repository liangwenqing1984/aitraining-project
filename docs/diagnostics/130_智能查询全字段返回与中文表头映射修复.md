# 智能查询全字段返回与中文表头映射修复

## 问题

1. 智能查询结果只显示少数几个字段，两张表的很多关键字段缺失
2. 表头显示英文（如 `companyName`）而非中文（如"企业名称"）

## 根因

### 问题1：LLM 自主选择 SELECT 字段

原 prompt（`prompts.ts:165`）仅弱提示：
```
SELECT 中列出 sp_jobs 的 company_name、job_name、work_city、salary_range、education、work_experience 等原始字段
```

LLM 常只选 3-5 个字段，增强字段几乎不包含。

### 问题2：字段名 camelCase 转换导致映射表失效

数据库查询链路：
```
PG 返回 snake_case → db.prepare().all() → convertRowsToCamelCase() → camelCase
```

但前端 `columnLabelMap` 的键都是 snake_case（如 `company_name`），永远匹配不上，`getColumnLabel()` 直接返回原始 camelCase 键名。

## 修复

### 后端 `prompts.ts`

强化 NL_QUERY_SYSTEM 规则：
- 必须用 `FROM sp_job_enrichments e LEFT JOIN sp_jobs j ON ...`
- SELECT 必须列出两张表全部 22 个字段（含别名前缀 `j.` / `e.`）
- 禁止使用 SELECT *
- 统计查询也尽量保留全部字段

### 前端 `query/Index.vue`

`columnLabelMap` 全部改为 camelCase 键名：

| 原(snake_case) | 改(camelCase) | 中文 |
|---------------|--------------|------|
| `company_name` | `companyName` | 企业名称 |
| `job_name` | `jobName` | 职位名称 |
| `salary_monthly_min` | `salaryMonthlyMin` | 月薪下限 |
| ... | ... | ... |

同时移除 raw_data 相关字段（这些不会被 SELECT 返回），保持映射精简准确。

## 涉及文件

- `code/backend/src/services/llm/prompts.ts` — prompt 强化
- `code/frontend/src/views/query/Index.vue` — 字段映射 camelCase 化

## 验证

重启 `start-dev.bat`，执行查询后检查：
1. 结果表格应显示 20+ 列字段
2. 所有表头应为中文
