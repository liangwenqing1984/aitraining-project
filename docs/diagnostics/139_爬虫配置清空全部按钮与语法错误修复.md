# 139 — 爬虫配置"清空全部"按钮与 EditTask 语法错误修复

**日期**：2026-05-11  
**分支**：with-dashboard  
**影响范围**：CreateTask.vue / BatchTaskCreator.vue / EditTask.vue

---

## 问题描述

### 1. 功能缺失

创建/编辑爬虫任务时，职位关键词和企业名称以标签列表形式展示。用户批量添加大量关键词后，若要全部删除，只能逐个点击标签的关闭按钮，操作繁琐。

### 2. EditTask 编译错误

为 EditTask.vue 添加 `clearCompanies()` 函数后，页面编译失败：

```
[vue/compiler-sfc] Unexpected token (279:0)
```

点击任务列表中已配置任务的"配置"按钮时，页面白屏报错。

---

## 根因分析

### 语法错误根因

编辑 `removeCompany` 函数的 old_string 为：

```js
// 移除企业
function removeCompany(index: number) {
  companies.value.splice(index, 1)
```

new_string 包含了完整的 `removeCompany` + `clearCompanies`：

```js
// 移除企业
function removeCompany(index: number) {
  companies.value.splice(index, 1)
}

function clearCompanies() {
  companies.value = []
}
```

但原文件中 `removeCompany` 后面还有一个 `}`（属于 `removeCompany` 的闭合），而 new_string 中已自带 `}`。结果新旧两个 `}` 叠加，导致多余的闭合花括号，触发 Babel 解析错误。

---

## 修复方案

### 文件变更

| 文件 | 变更内容 |
|------|---------|
| `CreateTask.vue` | 新增 `clearKeywords()` / `clearCompanies()` 函数；关键词和企业名称标签列表后添加 `<el-button type="danger" link>清空全部</el-button>` |
| `BatchTaskCreator.vue` | 新增 `clearKeywords()` 函数；关键词标签列表后添加清空全部按钮 |
| `EditTask.vue` | 同上 + 修复多余的 `}` 语法错误 |

### 核心代码

```typescript
function clearKeywords() {
  keywords.value = []
}

function clearCompanies() {
  companies.value = []
}
```

模板中按钮位置在 `tags-container` 内部末尾，仅当列表不为空时显示：

```html
<div class="tags-container" v-if="keywords.length > 0">
  <el-tag v-for="..." closable @close="removeKeyword(index)">{{ kw }}</el-tag>
  <el-button type="danger" link size="small" @click="clearKeywords" style="margin-left: 8px">清空全部</el-button>
</div>
```

### 按钮样式

- `type="danger"` — 红色文字表示危险操作
- `link` — 文字链接风格，不过度突出
- `size="small"` — 与标签尺寸协调
- `margin-left: 8px` — 与最后一个标签保持间距

---

## 验证方法

1. 进入「创建任务」，添加多个关键词 → 确认"清空全部"按钮出现 → 点击 → 确认全部删除
2. 同上验证企业名称
3. 进入任务列表，点击某任务的「配置」→ 确认页面正常加载，不报错
4. 在编辑页验证清空全部按钮功能

---

## 经验教训

- `Edit` 工具的 `old_string` 匹配范围应精确控制：本次误将 `removeCompany` 函数的闭合 `}` 排除在匹配范围外，导致残留
- 替换函数体时应同时匹配其闭合花括号，避免残留字符
- 多文件同类修改应先完成一个文件验证编译无误后，再批量应用到其他文件
