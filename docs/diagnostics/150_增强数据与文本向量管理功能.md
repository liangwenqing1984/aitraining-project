# 增强数据与文本向量管理功能

## 概述

在系统管理菜单下新增「增强数据管理」和「文本向量管理」两个子菜单，提供对 AI 增强数据和向量索引数据的在线增删改查能力，替代此前只能通过数据库命令行操作的限制。

## 一、增强数据管理

### 需求/问题
此前 `sp_job_enrichments` 表中的 AI 增强数据（薪资规范化、技能抽取、分类、学历标准化等）无法在前端查看和修改。数据有问题时只能直接操作数据库，操作门槛高且风险大。

### 实现
- **后端** `llmController.ts` 新增 5 个 CRUD 方法：分页列表、单条查询、更新、按任务批量删除、单条删除
- 列表接口 JOIN `sp_jobs` 表获取公司名、职位名等关联信息
- 更新接口仅允许修改 AI 增强产生的规范化字段（薪资、分类、技能、学历、经验等），不允许修改 id/task_id/job_id
- **路由** 注册在 `llmRoutes.ts`：`GET/PUT/DELETE /api/llm/enrich`
- **前端** `EnrichmentData.vue` 参照 `Users.vue` 的管理页面模式，提供搜索、表格、编辑对话框

### 关键文件
- `code/backend/src/controllers/llmController.ts` — 新增 `listEnrichments`、`getEnrichment`、`updateEnrichment`、`deleteEnrichmentsByTask`、`deleteEnrichment`
- `code/backend/src/routes/llmRoutes.ts` — 注册 5 条新路由
- `code/frontend/src/api/llm.ts` — 新增 5 个 API 函数
- `code/frontend/src/views/system/EnrichmentData.vue` — 新建页面

## 二、文本向量管理

### 需求/问题
语义搜索和问答机器人的向量索引数据分别存储在 `sp_job_embeddings` 和 `sp_doc_embeddings` 表中，此前无法在前端查看索引状态和管理数据（如删除过期索引、清理异常数据）。

### 实现
- 使用双 Tab 页面分别管理两类向量索引
- **职位向量 Tab**：分页列表、按 taskId 搜索、单条删除、按任务批量删除
- **文档向量 Tab**：分页列表、按 sourceType 筛选（帮助文档/用户手册/诊断文档/设计文档/后端源代码/前端源代码）、单条删除、按类型批量删除
- 来源类型用不同颜色的标签区分（warning/error/success/info）
- **后端新增**：
  - `ragController.ts` — `listJobEmbeddings` 分页查询职位向量
  - `docController.ts` — `listDocEmbeddings`、`deleteDocBySourceType`、`deleteDocBySection`
- **路由** 注册在 `ragRoutes.ts` 和 `chatRoutes.ts`

### 关键文件
- `code/backend/src/controllers/ragController.ts` — 新增 `listJobEmbeddings`
- `code/backend/src/controllers/docController.ts` — 新增 `listDocEmbeddings`、`deleteDocBySourceType`、`deleteDocBySection`
- `code/backend/src/routes/ragRoutes.ts` — 新增 `GET /index/records`
- `code/backend/src/routes/chatRoutes.ts` — 新增 `GET /docs/index/records` 和两个 DELETE 路由
- `code/frontend/src/api/chat.ts` — 新增 3 个文档向量管理函数
- `code/frontend/src/views/system/VectorData.vue` — 新建页面

## 三、路由与菜单

### 实现
- `router/index.ts` 注册 2 条新路由：`/system/enrichment` 和 `/system/vectors`
- `MainLayout.vue` 的 `defaultMenuItems` 中「系统管理」子菜单新增「增强数据管理」和「文本向量管理」
