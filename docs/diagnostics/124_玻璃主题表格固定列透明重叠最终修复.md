# 124 — 玻璃主题表格固定列透明重叠最终修复

## 问题

Element Plus 表格的 `fixed="right"` 操作列（固定列）在玻璃质感主题下，固定列 DOM 是独立渲染的，Element Plus 使用 `var(--el-table-bg-color)` 作为单元格背景色。全局 `style.css` 将 `--el-table-bg-color` 设为 `transparent`（实现玻璃透明效果），导致固定列单元格背景透明，底层正常表格内容穿透显示，造成"创建时间"列与"操作"列视觉重叠。

## 根因

三层原因叠加：

1. **全局 CSS 透明背景**：`style.css` 中 `.el-table { --el-table-bg-color: transparent; }` 使所有表格单元格透明
2. **`background` vs `background-color` 优先级**：Element Plus 内部使用 `background` 简写属性设置固定列背景，组件级 CSS 仅写 `background-color` 无法覆盖简写属性
3. **Vue scoped CSS 无法穿透 teleport/fixed DOM**：固定列 DOM 结构被 Element Plus 移出组件树，`:deep()` 选择器不一定命中所有内部元素

## 修复方案

### 全局层（style.css）

```css
.el-table .el-table__fixed-right,
.el-table .el-table__fixed-right .el-table__fixed-body-wrapper,
.el-table__fixed-right td,
.el-table__fixed-right th,
.el-table__fixed-right .el-table__cell,
.el-table__fixed-body-wrapper .el-table__cell {
  background: #fafafa !important;
  --el-table-bg-color: #fafafa !important;
  --el-table-tr-bg-color: #fafafa !important;
}
```

关键：使用 `background` 简写（非 `background-color`）+ 同时覆盖 CSS 变量。

### 组件层（crawler/Index.vue + files/Index.vue 非 scoped 块）

组件级也使用相同策略：`background` 简写 + CSS 变量双重覆盖，确保固定列单元格完全不透明。

## 涉及文件

| 文件 | 修改 |
|------|------|
| `code/frontend/src/style.css` | 全局固定列 `background` 简写 + CSS 变量 |
| `code/frontend/src/views/crawler/Index.vue` | 非 scoped 块 `.task-table` 固定列同策略 + `.el-table__cell` 选择器 |
| `code/frontend/src/views/files/Index.vue` | 非 scoped 块 `.files-table`/`.preview-table` 固定列同策略 |

## 附加修复：预览弹窗 body 横向滚动

`el-dialog` 被 teleport 到 `<body>`，scoped CSS 的 `:deep(.el-dialog__body)` 无法穿透。修复方式：
- `el-dialog` 添加 `class="preview-dialog"`
- 非 scoped 块添加 `.preview-dialog .el-dialog__body { overflow-x: auto; }`
