# 数据库设计

## 文档定位

本文件描述当前项目的数据库设计结果（schema `liangwenqing`，共 19 张表 + 20+ 个索引，含 pgvector 向量库和 RBAC 权限体系）。

## 数据实体

- **Task**（爬虫任务）：采集任务的配置、状态、进度和产出
- **Job**（原始职位）：爬虫采集的原始职位数据
- **CsvFile**（导出文件）：任务完成后的 Excel 文件元数据
- **LLMConfig**（AI 模型配置）：LLM 提供商的连接信息和任务路由
- **JobEnrichment**（AI 增强结果）：AI 对原始职位数据的标准化结果
- **MarketReport**（市场洞察报告）：AI 生成的分析报告和图表配置
- **SavedQuery**（NL 查询历史）：用户的自然语言查询记录和结果
- **JobEmbedding**（职位向量）：pgvector 职位语义向量索引
- **DocEmbedding**（文档向量）：项目文档和源代码的向量化存储
- **ChatSession**（对话会话）：AI 问答多轮对话会话管理
- **ChatMessage**（对话消息）：单轮对话消息和来源引用
- **TrainingJob**（训练任务）：Embedding 模型微调训练任务
- **User / Role / Permission / Menu**（RBAC）：用户-角色-权限-菜单四维权限体系

## 关键设计说明

- **主键策略**：业务表（sp_tasks/sp_csv_files/sp_jobs/sp_job_enrichments/sp_market_reports/sp_saved_queries/sp_chat_sessions/sp_chat_messages/sp_training_jobs）使用 UUID (VARCHAR(255))，sp_llm_config/sp_job_embeddings/sp_doc_embeddings 使用 SERIAL 自增整数
- **租户策略**：当前单 schema (`liangwenqing`)，无多租户隔离
- **逻辑删除策略**：不保留已删除记录（物理删除：DELETE CASCADE）
- **审计字段策略**：所有表包含 `created_at`，频繁更新的表额外包含 `updated_at`
- **JSONB 列**：sp_job_enrichments 使用 JSONB 存储技能和福利列表，sp_llm_config/sp_training_jobs 使用 JSONB 存储配置，sp_chat_messages 使用 JSONB 存储引用来源
- **ON CONFLICT UPSERT**：sp_job_enrichments 和 sp_job_embeddings 的 UNIQUE 约束支持幂等操作（覆盖更新）
- **pgvector 向量索引**：sp_job_embeddings 和 sp_doc_embeddings 使用 IVFFlat 索引加速余弦相似度搜索（768 维 nomic-embed-text 向量）

## 索引设计说明

- **高频查询场景**：`idx_tasks_status`（任务列表按状态筛选）、`idx_tasks_created_at`（任务列表按时间排序）
- **关联查询场景**：`idx_csv_files_task_id`（按任务查文件）、`idx_job_enrichments_task`（按任务查增强数据，增强/洞察/查询模块均依赖此索引）
- **报告查询场景**：`idx_market_reports_file`（按文件查报告历史）、`idx_saved_queries_task`（按任务查查询历史）
- **唯一约束场景**：`UNIQUE(task_id, job_id)` on job_enrichments
- **分页与排序场景**：`idx_tasks_created_at DESC`（任务列表按创建时间倒序）
