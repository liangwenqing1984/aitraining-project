# 语义模型训练

## 功能目标

从 AI 增强后的职位数据中提取对比学习训练对，通过 Python + sentence-transformers 微调训练自定义 embedding 模型，提升职位语义向量匹配的精准度。训练完成的模型可部署到 Ollama 供语义搜索和简历匹配使用。

## 业务流程

```
采集任务数据 → AI增强完成 → 构建训练数据集(JSONL)
  → 选择基座模型 + 超参数 → Python train_embedding.py 启动训练
  → 实时进度推送(STDOUT解析) → 训练完成 → 评估指标(metrics.json)
  → 部署到 Ollama → LLM路由配置 embedding 任务使用
```

## 训练数据集构建

### 数据来源

```sql
SELECT e.*, j.job_name, j.company_name, j.work_city
FROM sp_job_enrichments e
LEFT JOIN sp_jobs j ON e.job_id = j.job_id AND e.task_id = j.task_id
WHERE e.task_id IN ($taskIds)
  AND e.job_category_l1 IS NOT NULL
  AND e.job_category_l2 IS NOT NULL
```

### 三元组生成（对比学习）

```
Anchor(锚点) → 随机选取一条职位
Positive(正样本) → 同 job_category_l2 下的随机另一个岗位
Negative(负样本) → 不同 job_category_l1 的随机岗位
```

### 正样本策略

| 策略 | 值 | 说明 |
|------|-----|------|
| same_l2 | `same_l2` | 同 L2 子分类（推荐，区分度更高） |
| same_industry | `same_industry` | 同行业 |

### 输出格式（JSONL）

```json
{
  "anchor": "职位名称：Java高级工程师；公司：X科技；城市：北京；技能：Java, Spring, MySQL...",
  "positive": "职位名称：Java后端开发；公司：Y科技；城市：上海；技能：Java, SpringBoot, MyBatis...",
  "negative": "职位名称：会计出纳；公司：Z集团；城市：广州；技能：财务软件, Excel..."
}
```

### 启动训练请求

```json
POST /api/training/start
{
  "datasetPath": "data/training/dataset_xxx.jsonl",
  "baseModel": "nomic-ai/nomic-embed-text-v1.5",
  "params": {
    "epochs": 3,
    "batchSize": 16,
    "learningRate": 2e-5
  }
}
```

## 训练配置

### 可调参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| epochs | 3 | 训练轮数 |
| batchSize | 16 | 批次大小 |
| learningRate | 2e-5 | 学习率 |

### 基座模型

| 模型 HF ID | Ollama 对应 | 说明 |
|-----------|------------|------|
| `nomic-ai/nomic-embed-text-v1.5` | `nomic-embed-text:latest` | 推荐，英文为主 |
| `BAAI/bge-base-zh-v1.5` | `bge-base-zh:latest` | 中文优化 |
| `BAAI/bge-small-zh-v1.5` | `bge-small-zh:latest` | 轻量级中文 |
| `sentence-transformers/all-MiniLM-L6-v2` | `all-minilm:latest` | 通用轻量 |

### 训练环境

- Python 3.10+
- sentence-transformers + torch
- HF_ENDPOINT: `https://hf-mirror.com`（国内镜像加速）
- 模型输出目录：`data/models/model_{jobId}/`

## 实时进度推送

### 进度解析机制

```
Python STDOUT/STDERR → Node.js spawn 进程 → 每2秒刷入 DB
  ├─ PROGRESS:xx 行 → 直接解析百分比，立即刷新
  ├─ tqdm 进度条 → 正则提取 pct，映射到阶段区间
  │   ├─ 5-15%: 模型下载阶段
  │   └─ 20-85%: 训练阶段
  └─ 日志清理 → tqdm 控制字符过滤 → UTF-8 净化
```

### 日志过滤规则

- 清除 tqdm 进度条模式（`|fill| N/M [time]`）
- 清除 Unicode 块字符（U+2580-U+259F）
- 合并连续空行为双空行

## 数据关联

- `sp_training_jobs`：训练任务记录（name, status, progress, params, metrics, model_output_path, dataset_path, log）
- `sp_job_enrichments`：训练数据来源
- `data/training/`：JSONL 数据集存储目录
- `data/models/`：训练输出模型目录

## 异常处理

- 训练数据不足（< 2 条）→ 返回 `"训练数据不足：仅找到 N 条有效记录"`
- Python 不可用 → spawn 失败 → 任务标记 `failed`
- 训练脚本退出码非 0 → 任务标记 `failed`，stderr 写入日志
- 用户手动停止 → `taskkill`（Windows）/ `SIGTERM`（Linux）→ 任务标记 `stopped`
- HF 下载失败 → 使用 hf-mirror.com 镜像重试
