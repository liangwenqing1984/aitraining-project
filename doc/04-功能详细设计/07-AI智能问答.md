# AI 智能问答（HR 助手）

## 功能目标

基于 RAG（检索增强生成）的多轮对话系统，用户用自然语言提问系统相关问题，后端自动检索知识库（帮助文档/手册/诊断文档/源代码）→ 构建上下文 → LLM 生成带来源引用的回答。作为"HR 助手"提供即时技术支持和系统使用指导。

## 业务流程

```
用户提问 → 向量语义搜索(sp_doc_embeddings) + 内存关键词兜底
  → 合并去重 Top6 → 注入 System Prompt 构建上下文 → LLM 推理
  → 结构化回答 + 引用来源标注 → 保存会话 → 返回
```

## 知识库覆盖

| 来源类型 | source_type | 内容 | 索引方式 |
|----------|------------|------|---------|
| 帮助文档 | `doc_section` | 系统功能说明、API参考、使用指南 | HTML 分段 → 768维向量 |
| 用户手册 | `user_doc` | 安装部署、配置指南、常见问题 | Markdown 按 ## 标题分块 |
| 诊断文档 | `diagnostic` | 历史问题诊断、根因分析、修复方案 | Markdown 分块 |
| 设计文档 | `design_doc` | 需求、技术架构、功能设计、测试用例 | 按双空行分块 |
| 后端源代码 | `backend_source` | TypeScript 服务层/控制器/路由 | 按 export 边界分块 |
| 前端源代码 | `frontend_source` | Vue 组件逻辑、API封装、状态管理 | 按组件边界分块 |

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/chat/send` | 发送消息 → RAG 检索 → LLM 回复 |
| `GET` | `/api/chat/sessions` | 会话列表（按更新时间倒序） |
| `GET` | `/api/chat/sessions/:id` | 获取会话完整消息历史 |
| `DELETE` | `/api/chat/sessions/:id` | 删除会话（级联删除消息） |

## 双路检索策略

### 主路：向量语义搜索

```
用户问题 → nomic-embed-text → 768维向量
  → pgvector <=> 余弦距离 → sp_doc_embeddings
  → 相似度阈值 0.2 → Top5
```

### 辅路：内存关键词兜底（fallbackSearch）

始终执行，确保向量搜索失败时也能召回：

- **双字分词**：中文按所有相邻二字组合匹配（如"语义搜索" → [语义, 义搜, 搜索]）
- **ILIKE 模糊匹配**：数据库源码表
- **硬编码帮助文档**：预定义的 DOC_SECTIONS 匹配
- **得分规则**：标题命中 +5，内容命中 +1

### 合并去重

- 向量结果优先，内存结果补充
- 最多 6 个章节（控制 LLM 上下文长度）
- 来源类型标注：`[帮助文档]`、`[诊断文档]`、`[后端源代码]` 等

## RAG System Prompt 设计

```
你是招聘职位智能采集与分析系统的智能助手。

## 知识范围：帮助文档、用户手册、诊断文档、设计文档、后端/前端源代码

## 你的职责：
1. 优先根据参考内容回答问题
2. 综合多种来源并注明来源类型
3. 无相关信息时诚实告知，不编造
4. 涉及 API/配置/代码时给出准确信息
5. 使用中文回答
```

## 业务规则

- **消息长度限制**：单条消息 ≤ 2000 字符
- **会话标题**：首次提问自动截取前 30 字符作为标题
- **来源持久化**：sources 以 JSON 存入 sp_chat_messages，支持历史回溯
- **LLM 容错**：LLM 调用失败时返回友好提示 `"AI 服务暂时不可用，请检查模型配置后重试"`
- **多重降级**：向量搜索失败 → 关键词兜底 → LLM 失败 → 错误提示

## 文档向量化索引

### 索引入口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/docs/index` | 启动文档索引（支持按 sourceType 过滤） |
| `GET` | `/api/docs/index/status` | 获取索引状态 |
| `GET` | `/api/docs/index/records` | 列出已索引的文档向量记录（分页） |
| `POST` | `/api/docs/index/file` | 上传文件并自动分块索引 |
| `DELETE` | `/api/docs/index/:sectionId` | 删除指定章节的索引 |
| `DELETE` | `/api/docs/index/source/:sourceType` | 删除指定来源类型的所有索引 |

### 分块策略

| 内容类型 | 分块方法 | 最大块长度 |
|----------|---------|-----------|
| HTML 文档 | 按句号分割 | 3000 字符 |
| Markdown | 优先按 ## 标题分割 | 3000 字符 |
| Markdown 长章节 | 按句号二次分割 | 3000 字符 |
| 源代码 | 按双空行 + export 边界分割 | 3000 字符 |

## 数据关联

- `sp_chat_sessions`：会话记录（title, created_at, updated_at）
- `sp_chat_messages`：消息记录（session_id, role, content, sources JSON）
- `sp_doc_embeddings`：文档向量索引（section_id, chunk_index, text_content, embedding vector(768), source_type, file_path）

## 异常处理

- pgvector 不可用 → 跳过向量搜索，仅使用内存关键词兜底
- LLM 调用超时 → 返回 `"AI 服务暂时不可用"`
- 消息内容为空 → 返回 400 `"消息内容不能为空"`
- 消息过长 → 返回 400 `"消息内容过长，请限制在2000字以内"`
- 会话不存在 → 自动创建新会话
