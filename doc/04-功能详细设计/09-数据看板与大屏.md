# 数据看板与可视化大屏

## 功能目标

提供全库职位数据的聚合统计视图（数据看板）和科技蓝风格全屏可视化展示（可视化大屏），支持多维度图表交互、AI 全量洞察报告、区域分布分析。

## 数据看板 (Dashboard)

### 路由

- `/dashboard` → `code/frontend/src/views/dashboard/Index.vue`

### 统计卡片

| 卡片 | 说明 |
|------|------|
| 总职位数 | `SELECT COUNT(*) FROM sp_job_enrichments` |
| 任务总数 | `SELECT COUNT(*) FROM sp_tasks` |
| 企业数量 | `SELECT COUNT(DISTINCT company_name) FROM sp_job_enrichments` |
| 城市覆盖 | `SELECT COUNT(DISTINCT work_city) FROM sp_job_enrichments` |
| 平均月薪 | `AVG(salary_monthly_max)` |

### 图表维度

| 图表 | 类型 | 数据来源 |
|------|------|---------|
| 黑龙江省地图 | ECharts 地图 | `/api/regions/stats?dim=city` |
| 经验年限分布 | 柱状图 | `/api/dashboard/overview` |
| 技能词云 | 词云图 | `/api/dashboard/overview` |
| 学历分布 | 饼图 | `/api/dashboard/overview` |
| 薪资区间分布 | 柱状图/箱线图 | `/api/dashboard/overview` |
| 城市分布 | 柱状图 | `/api/dashboard/overview` |

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/dashboard/overview` | 全库概览统计（含 6 维度分布 + 技能词云） |
| `GET` | `/api/regions/stats?dim=city` | 黑龙江省区域分布统计 |

## 可视化大屏 (Daping)

### 路由

- `/daping` → `code/frontend/src/views/daping/Index.vue`

### 页面特征

- **风格**：深色科技蓝主题，全屏自适应布局
- **布局**：多栏网格布局，图表卡片式排列
- **图表组件**：基于 ECharts 6，支持 dark 主题
- **实时数据**：页面加载时调用 Dashboard API 获取最新全库统计数据

### 展示内容

| 区域 | 内容 |
|------|------|
| 顶部统计栏 | 总职位/任务/企业/城市数（大数字动画效果） |
| 地图区域 | 中国地图 / 黑龙江地图（区域分布热力） |
| 图表区 | 薪资分布、学历分布、经验分布、技能词云、行业分布 |
| 底部信息 | 系统名称、版本号、数据更新时间 |

## AI 全量洞察

在数据看板基础上，对接 LLM 生成全库数据的综合分析报告：

- **触发方式**：看板页点击"AI 全量洞察"按钮
- **数据处理**：聚合全库多维度统计数据 → 注入 LLM Prompt → 生成报告
- **报告结构**：市场总览 + 各维度分析 + 关键发现 + 建议
- **存储**：报告存入 `sp_market_reports` 表，支持历史查看
- **实时进度**：WebSocket 推送 `insights:progress` + `insights:completed`

const [overview, regionStats] = await Promise.all([

## 业务规则

- **数据阈值**：只有 `sp_job_enrichments` 中有数据时才渲染图表（空库显示占位提示）
- **缓存策略**：看板数据前端缓存 5 分钟，减少重复请求
- **响应式**：图表随窗口 resize 自适应，最小支持 1280×720 分辨率
- **加载状态**：数据加载中使用骨架屏/loading 动画，避免白屏

## 数据关联

- `sp_job_enrichments`：看板统计数据来源
- `sp_tasks`：任务统计
- `sp_market_reports`：AI 洞察报告存储
- 无需额外建表，数据从已有业务表聚合计算
